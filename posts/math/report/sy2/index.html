实验三 生物电信号采集与数据处理 实验报告

2026年5月10日
|

一、实验目的

本次实验通过采集并分析心电信号，旨在了解心电信号特性和采集心电数据的方法，学习使用口袋仪器产生测试信号的方法，运用Matlab软件进行数据分析，定量检验数据的可靠性，同时理解处理ECG的诸多算法和流程。借此实验，探究“模拟信号验证 - 真实信号采集”的实验思想，拓宽生物电信号处理的工程视野，培养耐心细致的实验素养、逐步排查问题的逻辑思想，激发对电电理论课的探索热情。具体实验目的如下。

（一） 知识理解与技能掌握

  1. 了解心电图（Electrocardiograph, ECG）的特征与采集方法，学习使用 ADS1292R 生物电信号采集芯片从人体获取 ECG 信号，了解不同导联的信号特征。
  2. 熟悉口袋仪器（Analog Discovery 3）的基本原理和功能，学会运用此仪器产生给定波形数据的测试信号。
  3. 学习Matlab软件的基本功能和使用方法，利用该软件进行初步数据处理和分析，为后续其他研究打下基础。
  4. 掌握心电信号采集设备的操作规范和调试技巧，从而确保数据的准确性和可靠性。

（二） 实验探究与知识拓展

  1. 贯彻“先模拟验证，后真实采集”的工程逻辑。通过 Analog Discovery 3 导入预设的 .csv 格式模拟心电（ECG）信号作为标准源，对 ADS1292R 采集系统的还原准确性进行定量验证。在接入人体生理信号前，排除硬件电路自身潜在故障，确保不存在硬件误差导致的实验偏差。
  2. 进一步拓宽生物医学信号处理的工程视野，要求掌握 ECG 采集套件各硬件模块的功能机理，并实践基于 Matlab 的信号处理全流程，包括调用峰值检测函数、 PanTompkins 算法等。

（三）情感与素养

培养“耐心采集、细致记录”的实验态度，学会主动逐步排障，增强在复杂工程环境下的抗挫折能力与系统化思维。通过生物电信号、模拟电路与数字算法的交叉应用，促进跨学科知识的深度融合与综合素养提升，领悟学科魅力，激发对电电理论课的学习兴趣和探索热情。

二、实验内容

（一） 验证 ADS1292R 生物电信号采集芯片是否能正确采集 ECG 信号

1. 心电信号 ECG

心电信号（Electrocardiogram, ECG）是心脏在生理活动过程中，由心肌细胞除极和复极所产生的生物电信号在体表的综合反映。该信号蕴含了人体心血管系统重要的生理与病理信息，是临床医生评估心脏健康状况、诊断心脏疾病（如心律失常、心肌缺血等）及制定治疗方案的核心依据。在实验或临床操作中，心电信号通过贴附在人体皮肤表面的电极进行采集。由于原始生物电信号极其微弱且伴有噪声干扰，获取后需经过专用电路进行放大与滤波处理，最终形成可供记录和分析的电压随时间变化的波形图。

典型的心电信号在时间轴上呈现出显著的周期性，每个心动周期均由一系列具有特定生理含义的波形组成。其中，P波反映了心房肌的兴奋与收缩过程，通过观察其形态和持续时间可评估心房的健康状态；紧随其后的QRS波群代表心室肌的兴奋与收缩，是心电信号中振幅最大的部分，对于诊断各类心律失常具有核心价值；T波则对应心室肌的复极过程，其形态异常往往预示着心肌受损。除了特征波形外，PR间期衡量了兴奋从心房传导至心室的时间跨度，而QT间期则涵盖了心室肌从除极到复极的完整电活动周期。通过对这些波形的形态、振幅及时间间距进行综合分析，能够有效评估心脏的功能状态，并为心肌缺血、心律失常等病症的诊断提供科学依据。

2. 心电数据集

本实验所采用的数据源自国际公认的 MIT-BIH 心律失常数据库。该数据库由麻省理工学院提供，因其详尽的专家注释和标记，已成为心律失常分类及临床研究的标准数据集。数据库涵盖了 47 名受试者的 48 组、每组时长约 30 分钟的双导联心电记录，总计包含约 109,500 个心拍，其中异常心拍占比约 30%，涵盖了正常心跳、房颤及室上性早搏等多种典型波形。实验数据以 .dat 和 .atr 格式存储，通过文件编号对应不同个体的采集样本。本实验利用这些标准信号进行信号读取与检验，验证生物电信号采集芯片可以正确采集心电数据，同时通过对双导联数据的分析，实现对不同心电特征的准确提取与识别。

3. ADS1292R ECG数据采集套件

本实验采用一套集成化的生物电信号采集套件，可以实现心电信号的稳定获取与无线传输。系统硬件核心为 ADS1292R 生物电信号采集模块，该模块内置信号调理放大电路及 24 位高分辨率模数转换器，在本实验中设定采样率为 500sps，足够精确捕捉微弱的生物电变化。系统控制中枢采用 STM32F103C8T6 微控制器，通过 SPI 协议与 ADS1292R 进行同步通信，实时接收并缓存采集到的数字信号。数据处理后，利用 JDY18 蓝牙模块 经 USART 接口将数据无线传输至PC端的蓝牙适配器，完成数据的存储与管理。此外，系统配备了完善的充电与升压电路以保障电源供应。

4. Analog Discovery 3 口袋仪器

本实验采用 Digilent 公司的 Analog Discovery 3 (AD3) 多功能测试设备作为信号源，用于模拟人体心电信号的输出。AD3 是一款集成度极高的“口袋仪器”，在本实验中主要利用其任意波形发生器（AWG）功能，输出 MIT-BIH 数据库中的心电波形。该设备拥有两个 141414 位分辨率的差分输出通道，采样速率高达 125MS/s125 MS/s125MS/s，支持 ±5V\pm5V±5V 的输出范围，能够产生高精度的模拟微弱信号。实验过程中，通过配套的 WaveForms 软件 进行波形配置与控制，将预设的心电波形数据导入 AD3，经由数模转换（DAC）输出至采集系统前端。这一环节通过标准化的模拟信号输入，为验证 ADS1292R 采集模块的放大性能及模数转换的准确性提供了参考标准。

5. 模拟信号产生与读取

本实验通过实验室电脑中已经存储的 ECG 信号文件，通过 WaveForms软件读取并使用 Analog Discovery 3 仪器生成波形，通过更改 Nsample 和 index 两个数据的方式生成不同心率的不同波形，最终利用 ADS1292R 芯片采集并记录生成的模拟信号，包含波形数据以 csv格式保存和截屏保存两个步骤。

根据本实验步骤的脚本设置（Wavegen.Channel1.Custom.SampleRate.value = 16000 * 360 / Nsample;），生成的心率与 Nsample 的换算关系是 HR=21600NsampleHR=\frac{21600}{Nsample}HR=Nsample21600​。因此，当 NSample 设置为 301301301时，心率应当为 717171 左右。通过设置不同的 Nsample 大小，可以调整生成心电波形的心率。

（二）人体 ECG 信号采集

1. 导联方式

在人体 ECG信号采集过程中，可以采用不同的导联方式，即电极附在人体身上的不同部位。导联方式决定了波形特征和形状，亦有独特的医学用途。

a. 标准肢体导联

标准肢体导联属于双极导联，主要记录人体四肢中两点之间的电位差。它包括 Ⅰ、Ⅱ、Ⅲ 三个导联。Ⅰ 导联记录左上肢与右上肢之间的电位差，Ⅱ 导联记录左下肢与右上肢之间的电位差，Ⅲ 导联记录左下肢与左上肢之间的电位差。在生理实验中，由于 Ⅱ 导联的轴向与心脏除极的总电向量方向最为接近，通常能获取到振幅最明显、特征最清晰的 P 波与 R 波，常被选作基础心电监测的首选导联。

b. 加压单极肢体导联

加压单极肢体导联是一种单极测量方式，包括 aVR、aVL 和 aVF。其原理是将肢体中的两个电极通过电阻连接作为参考负极，以测量另一个肢体探测电极与该参考点之间的绝对电位变化。这类导联能够从额面角度提供补充的心电向量信息，有助于更全面地评估心脏电活动在不同空间方向上的投影。

c. 标准胸前导联

标准胸前导联（V1-V6）属于单极导联，通过将探测电极放置在胸壁的特定解剖位置，记录心脏电活动在水平面上的投影。胸前导联能够近距离观察心脏各部位（如右心室、室间隔、左心室壁）的电变化，对于诊断局部心肌梗死、心室肥大等病症具有不可替代的作用。

d. 双极胸导联

双极胸导联是科研实验或运动心电监测中常用的简化导联方式，其电极均放置在胸壁。其记录的是胸腔表面两点间的电位差，而非相对于中心电端的绝对电位。这种方式通过缩短电极间距、避开肢体肌肉，能有效抑制肌电干扰等影响因素。由于电极位置的灵活性，其波形极性取决于正负电极相对于心脏电轴的具体位置。

本实验选做部分采用的“左胸 - 右胸”的电极设置方式属于CC5导联，这是一种双极胸导联，也属于一种改良Ⅰ导联，这种导联方式常见于便携式心电检测或生物医学工程实验。必做部分采用的 MIT-BIH 数据库大部分采用改良 Ⅱ 导联与改良 V1 导联，这种双导联方式适合长时间观测、减少肌电干扰。因此，实验两个步骤记录的波形会有区别。

2. 误差预测

在测量人体ECG信号时，主要的误差来源首先是工频干扰。这通常是由人体、导联线与周围电力设施（50Hz/60Hz）之间的电容耦合引起的。这种干扰会在波形上叠加一个高频率的正弦背景，可能会严重掩盖P波和T波等微弱特征。

其次是肌电干扰。这主要源于受试者肢体紧张或不由自主的肌肉颤抖。由于肌电信号的频谱范围与ECG有重叠，这类干扰是不规则的高频杂波，会导致波形基线变得粗糙模糊。在实验过程中，保持受试者身体完全放松并采取舒适的坐姿或卧姿是减少此类物理误差的关键。

基线漂移也是常见的误差，通常由受试者的呼吸运动或电极与皮肤接触点的电位变化引起。呼吸导致的胸廓起伏会使电极发生微小位移，使ECG波形在垂直方向上缓慢上下波动。这种低频干扰会影响对ST段偏移的准确判断，通常需要通过高通滤波器进行抑制。

电极与皮肤的接触阻抗不均匀会导致共模干扰转化为差模干扰。如果皮肤表面的油脂或角质层未经过酒精清理，各电极间的阻抗匹配失衡，会直接降低放大电路的有效放大倍数，并增加随机热噪声。在电极安放前进行必要的皮肤预处理是确保信号信噪比的基础。

最后是电磁兼容性引起的射频干扰。实验室环境中的手机、电脑或大型医疗设备的射频辐射可能通过空间耦合进入采集系统，表现为周期性或突发的尖峰脉冲。这类误差虽然不属于生物信号范畴，但在高增益的生理电放大电路中极易被放大，导致AD采集结果出现异常值或波形失真。

在本次实验中，我们主要关注工频干扰、基线漂移、肌电干扰，这是三个最主要的干扰源。

本实验通过特定的导联方式采集心电数据，重复必做部分的数据采集步骤，记录对应的 csv 数据，以便进一步分析。

（三）生物电信号数据处理

在本实验中，选用Matlab软件对 Analog Discovery3 仪器生成的的心电信号进行分析、处理和图像绘制。首先用Matlab根据数据绘制ECG图像，观察并判断输出波形中是否有无效部分；随后设计算法，统计心电数据中 R 峰的位置，据此统计心率。最后利用实际的ECG信号，通过Pan-Tompkins算法等算法进行处理，再输出ECG信号图像，并标注出R峰的位置，从而进行心率统计。

在科研中，分析心电图的最佳方法是 Pan-Tompkins 算法。查询可知，它首先利用带通滤波器滤除基线漂移、工频干扰及肌电噪声，随后对信号进行一阶微分处理以强化 QRS 波群的斜率信息。为了进一步突出波峰并消除负向波的影响，算法对微分后的信号进行平方运算，将斜率特征转化为非负的能量脉冲。在获得能量特征后，算法采用移动窗口积分器对平方后的信号进行平滑处理，积分窗口的宽度通常根据典型的 QRS 复波时限设定，旨在获得一个反映波群包络的脉冲信号。最后，算法结合双重自适应阈值机制与回溯检测策略，通过对信号电平和噪声电平的实时估算，从积分结果中精确定位 R 波的位置。这种变换流程利用了 QRS 波群在高频成分、斜率及能量分布上的特征，确保了检测在复杂背景噪声下的稳健性。

function [r_peaks, avg_HR] = pan_tompkins_detector(ecg, fs)
	
	% 原始数据处理和变量定义
	ecg = ecg(:);
	ecg_raw = ecg;
	N = length(ecg);    
    
    % 为了方便后续的积分，对数据先进行归一化。
    ecg = ecg - mean(ecg); 
    ecg = ecg / max(abs(ecg)); 
    
    %% 带通滤波器的实现
    % 低通滤波器，设定在15Hz截止。低通滤波器主要用来消除肌电干扰。
    N_lpf = round(fs / 30); 
    if N_lpf < 1, N_lpf = 1; end
    lpf_tmp = zeros(N, 1); % 初始化中间变量与输出序列
    ecg_lpf = zeros(N, 1); % 初始化中间变量与输出序列
    
    for n = N_lpf:N
        lpf_tmp(n) = sum(ecg(n-N_lpf+1 : n)) / N_lpf;
    end % 第一级滑动平均，初步平滑信号，抑制高频噪声
    for n = N_lpf:N
        ecg_lpf(n) = sum(lpf_tmp(n-N_lpf+1 : n)) / N_lpf;
    end % 第二级滑动平均，进一步增强滤波效果，使波形更平滑
    delay_lpf = N_lpf - 1; % 计算群延迟，在后面会进行对齐
    
    % 高通滤波器 ，设定在5Hz截止。高通滤波器主要用来消除基线漂移的情形。
    N_hpf = round(fs / 5); 
    if N_hpf < 1, N_hpf = 1; end
    delay_hpf = round((N_hpf - 1) / 2); % 计算滑动平均器的中心延迟
    ecg_hpf = zeros(N, 1);
    
    for n = N_hpf:N
        ma = sum(ecg_lpf(n-N_hpf+1 : n)) / N_hpf; % 计算当前窗口内的均值（代表基线分量）
        ecg_hpf(n) = ecg_lpf(n - delay_hpf) - ma; % 从原始信号中减去基线分量，实现高通滤波效果
    end
    
    %% 求导的实现
    ecg_diff = zeros(N, 1);
    for n = 5:N
        ecg_diff(n) = (1/8)*(2*ecg_hpf(n) + ecg_hpf(n-1) - ecg_hpf(n-3) - 2*ecg_hpf(n-4));
    end
    delay_diff = 2; % 理论群延迟
    
    %% Step 3: 对信号进行平方处理，放大高频成分
    ecg_sq = ecg_diff .^ 2;
    
    %% Step 4: 对信号进行滑动窗口积分
    win_size = round(0.150 * fs); % 150ms 窗口理论上可以完全覆盖整个QRS能量
    ecg_mwi = zeros(N, 1);
    for n = win_size:N
        ecg_mwi(n) = sum(ecg_sq(n-win_size+1 : n)) / win_size;
    end
    delay_mwi = round((win_size - 1) / 2); % 计算理论延迟
      
    %% Step 5: 自适应阈值状态机 (精简稳定版)
    r_locs = [];
    SPKI = 0;
    NPKI = 0;
    % 初始化阈值为前2秒最大值的 30%
    threshold_I1 = max(ecg_mwi(1:min(round(2*fs), N))) * 0.3; 
    
    refractory_samples = round(0.250 * fs); % 在250ms以内不接受新的波峰
    
    for i = 2:length(ecg_mwi)-1
        if ecg_mwi(i) > ecg_mwi(i-1) && ecg_mwi(i) >= ecg_mwi(i+1)
            PIAKI = ecg_mwi(i);
            
            if PIAKI > threshold_I1
                % 如果和上一个数据点的差距小于 250ms ，且比上一个数据点的峰值更小，则不录入这个数据
                if isempty(r_locs) || (i - r_locs(end)) > refractory_samples
                    r_locs(end+1) = i;
                    SPKI = 0.125*PIAKI + 0.875*SPKI;
                else
                    % 如果在250ms内又出现了高大的峰，通常视为噪声或波形畸变，更新噪声均值
                    NPKI = 0.125*PIAKI + 0.875*NPKI;
                end
            else
                NPKI = 0.125*PIAKI + 0.875*NPKI;
            end
            
            threshold_I1 = NPKI + 0.25*(SPKI - NPKI);
        end
    end
    
    %% 补偿前面进行过的延迟，进行局部去基线波峰搜索
    r_peaks = zeros(size(r_locs));
    
    % 汇总前述所有步骤的理论延迟，计算出总延迟
    total_delay = delay_lpf + delay_hpf + delay_diff + delay_mwi;
    search_radius = round(0.12 * fs); % ±120ms 搜索半径
    
    for i = 1:length(r_locs)
        % 补偿延迟，定位回原始物理时间点
        true_loc = r_locs(i) - total_delay;
        true_loc = max(1, min(N, true_loc));
        
        % 确定搜索窗口，以补偿后的位置为中心，在指定半径内寻找极值
        idx_start = max(1, true_loc - search_radius);
        idx_end   = min(N, true_loc + search_radius);
        win = idx_start : idx_end;
        
        local_sig = ecg_raw(win); % 获取原始心电信号中的局部波形
        
        % 局部线性去趋势，消除搜索窗口内的残余基线漂移干扰
        slope = (local_sig(end) - local_sig(1)) / (length(local_sig) - 1);
        baseline = local_sig(1) + slope * (0:length(local_sig)-1)';
        local_sig_detrend = local_sig - baseline;
        
        % 在去除了漂移干扰的局部信号中找最大值索引
        [~, max_idx] = max(local_sig_detrend); 
        r_peaks(i) = win(1) + max_idx - 1;
    end
    
    %% Step 7: HR 计算
    if length(r_peaks) > 1
        rr = diff(r_peaks) / fs;
        HR = 60 ./ rr;
        avg_HR = mean(HR);
    else
        avg_HR = 0; 
    end
end

五、实验总结

本次实验真实地构建了“模拟信号验证 - 真实信号采集”的工程闭环。实验初期，利用 Analog Discovery 3 (AD3) 口袋仪器作为标准信号源，将 MIT-BIH 数据库中的标准心电波形输入 ADS1292R 采集系统。通过定量对比预设心率与实际采集心率，验证了硬件系统在信号放大与模数转换过程中的准确性。在确保硬件可靠的基础上，实验进一步开展了不同导联方式下的人体心电信号采集，并重点探究了实际生理信号中存在的干扰抑制与算法提取问题。

实验结果显示，ADS1292R 模块能够稳定获取 24 位高分辨率心电数据，采样率设定为 500sps。尽管原始数据存在约 2232^{23}223 的直流偏置（系统采用偏移二进制码导致），但在应用差分处理或去均值算法后，波形特征（P波、QRS波群、T波）清晰可见，心电数据满足分析需求。

在人体采集环节，通过对比 L/R 极调换前后的波形，验证了实验所采用的双极胸导联（CC5导联）特性。实验观察到，在该导联下 T 波振幅较大且与 R 波方向相反，这反映了探测电极靠近心尖部时，心室复极向量在局部投影较强的生理特征。

本实验还对比了手动阈值统计方法和Pan-Tompkins算法在不同场景下的表现。由于 MIT-BIH 标准信号背景纯净、基线平稳，简单的幅度阈值法即可准确提取 R 峰，两种方法所得心率值与理论值偏差极小。在实际采集人体 ECG 信号过程中，信号受到明显的基线漂移和工频干扰影响。固定阈值无法适应起伏的基线，导致在基线抬升处出现误检。而对比之下，Pan-Tompkins算法通过级联带通滤波、微分、平方及移动窗口积分，有效地识别了 QRS 波群的斜率信息，并准确标注出了R峰的位置。实验证明，该算法配合自适应阈值机制，能够有效克服基线漂移，准确锁定人体实时心率。

通过本次实验，掌握了生物电信号采集的硬件配置、导联规范及 Matlab 信号处理全流程。实验过程中针对电极极性、基线干扰等问题的排查，加深了对模拟电路与数字算法交叉应用的理解。
