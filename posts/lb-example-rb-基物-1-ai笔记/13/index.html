    波的干涉

    1. 波的叠加原理

    当空间中同时存在多个波源时，每个波都独立地传播并满足线性叠加原理。设有一系列波函数 ψ1,ψ2,…\psi_1, \psi_2, \dotsψ1​,ψ2​,…，则总波函数为：

    ψtot=∑iψi\psi_{\text{tot}} = \sum_i \psi_iψtot​=i∑​ψi​

    关键点： 振幅满足叠加原理，但强度并不简单地满足 ∣ψtot∣2=∑i∣ψi∣2|\psi_{\text{tot}}|^2 = \sum_i |\psi_i|^2∣ψtot​∣2=∑i​∣ψi​∣2。这正是干涉现象的本质。

    2. 复振幅表示与相位图

    我们用复数形式表示简谐波：

    ψ~1=A0ei(kx−ωt)\tilde{\psi}_1 = A_0 e^{i(kx - \omega t)}ψ~​1​=A0​ei(kx−ωt) ψ~2=A0ei(kx−ωt+ϕ0)\tilde{\psi}_2 = A_0 e^{i(kx - \omega t + \phi_0)}ψ~​2​=A0​ei(kx−ωt+ϕ0​)

    将两者相加：

    ψ~tot=A0ei(kx−ωt)+A0ei(kx−ωt+ϕ0)=A0ei(kx−ωt)(1+eiϕ0)\tilde{\psi}_{\text{tot}} = A_0 e^{i(kx - \omega t)} + A_0 e^{i(kx - \omega t + \phi_0)} = A_0 e^{i(kx - \omega t)}(1 + e^{i\phi_0})ψ~​tot​=A0​ei(kx−ωt)+A0​ei(kx−ωt+ϕ0​)=A0​ei(kx−ωt)(1+eiϕ0​)

    利用欧拉公式 eiϕ0=cos⁡ϕ0+isin⁡ϕ0e^{i\phi_0} = \cos\phi_0 + i\sin\phi_0eiϕ0​=cosϕ0​+isinϕ0​，可将括号内复数化为几何形式：

    1+eiϕ0=(1+cos⁡ϕ0)+isin⁡ϕ01 + e^{i\phi_0} = (1 + \cos\phi_0) + i\sin\phi_01+eiϕ0​=(1+cosϕ0​)+isinϕ0​

    求其模长：

    ∣1+eiϕ0∣2=(1+cos⁡ϕ0)2+sin⁡2ϕ0=2+2cos⁡ϕ0=4cos⁡2ϕ02|1 + e^{i\phi_0}|^2 = (1 + \cos\phi_0)^2 + \sin^2\phi_0 = 2 + 2\cos\phi_0 = 4\cos^2\frac{\phi_0}{2}∣1+eiϕ0​∣2=(1+cosϕ0​)2+sin2ϕ0​=2+2cosϕ0​=4cos22ϕ0​​

    故 ∣1+eiϕ0∣=2∣cos⁡(ϕ0/2)∣|1 + e^{i\phi_0}| = 2|\cos(\phi_0/2)|∣1+eiϕ0​∣=2∣cos(ϕ0​/2)∣，而相位角为 arg⁡(1+eiϕ0)=ϕ0/2\arg(1 + e^{i\phi_0}) = \phi_0/2arg(1+eiϕ0​)=ϕ0​/2（当 cos⁡(ϕ0/2)>0\cos(\phi_0/2) > 0cos(ϕ0​/2)>0 时）。因此：

    ψ~tot=A0⋅2cos⁡ϕ02⋅ei(kx−ωt+ϕ02)\tilde{\psi}_{\text{tot}} = A_0 \cdot 2\cos\frac{\phi_0}{2} \cdot e^{i\left(kx - \omega t + \frac{\phi_0}{2}\right)}ψ~​tot​=A0​⋅2cos2ϕ0​​⋅ei(kx−ωt+2ϕ0​​)

    由此可得有效振幅为 2A0cos⁡(ϕ0/2)2A_0\cos(\phi_0/2)2A0​cos(ϕ0​/2)。

    相位图（Phasor Diagram）分析

    由于两波频率相同，在复平面上它们的相位向量（phasor）长度均为 A0A_0A0​，夹角为 ϕ0\phi_0ϕ0​。合向量的模长即为上述推导的 ∣1+eiϕ0∣=2cos⁡(ϕ0/2)|1 + e^{i\phi_0}| = 2\cos(\phi_0/2)∣1+eiϕ0​∣=2cos(ϕ0​/2)，方向指向角平分线。

    3. 干涉类型

    基于相位差 ϕ0\phi_0ϕ0​：

    类型相位关系有效振幅

    4. 干涉的一般理论

    4.1 从叠加原理到干涉项

    设两列波场分别为 E~1\tilde{E}_1E~1​ 和 E~2\tilde{E}_2E~2​，总场为 E~tot=E~1+E~2\tilde{E}_{\text{tot}} = \tilde{E}_1 + \tilde{E}_2E~tot​=E~1​+E~2​。测量到的强度是时间平均的模方：

    Itot=⟨∣E~tot∣2⟩t=⟨E~tot∗E~tot⟩tI_{\text{tot}} = \langle |\tilde{E}_{\text{tot}}|^2 \rangle_t = \langle \tilde{E}_{\text{tot}}^* \tilde{E}_{\text{tot}} \rangle_tItot​=⟨∣E~tot​∣2⟩t​=⟨E~tot∗​E~tot​⟩t​

    将 E~tot=E~1+E~2\tilde{E}_{\text{tot}} = \tilde{E}_1 + \tilde{E}_2E~tot​=E~1​+E~2​ 代入并展开：

    E~tot∗E~tot=(E~1∗+E~2∗)(E~1+E~2)=∣E~1∣2+∣E~2∣2+E~1∗E~2+E~2∗E~1\tilde{E}_{\text{tot}}^* \tilde{E}_{\text{tot}} = (\tilde{E}_1^* + \tilde{E}_2^*)(\tilde{E}_1 + \tilde{E}_2) = |\tilde{E}_1|^2 + |\tilde{E}_2|^2 + \tilde{E}_1^* \tilde{E}_2 + \tilde{E}_2^* \tilde{E}_1E~tot∗​E~tot​=(E~1∗​+E~2∗​)(E~1​+E~2​)=∣E~1​∣2+∣E~2​∣2+E~1∗​E~2​+E~2∗​E~1​

    对时间取平均，由于 ∣E~1∣2|\tilde{E}_1|^2∣E~1​∣2 和 ∣E~2∣2|\tilde{E}_2|^2∣E~2​∣2 为单色波的常数时间平均：

    ⟨∣E~1∣2⟩t=I1,⟨∣E~2∣2⟩t=I2\langle |\tilde{E}_1|^2 \rangle_t = I_1, \quad \langle |\tilde{E}_2|^2 \rangle_t = I_2⟨∣E~1​∣2⟩t​=I1​,⟨∣E~2​∣2⟩t​=I2​

    而交叉项 E~1∗E~2+E~2∗E~1=2 Re(E~1∗E~2)\tilde{E}_1^* \tilde{E}_2 + \tilde{E}_2^* \tilde{E}_1 = 2\,\text{Re}(\tilde{E}_1^* \tilde{E}_2)E~1∗​E~2​+E~2∗​E~1​=2Re(E~1∗​E~2​)，其时间平均依赖于两波的相位关系。

    4.2 具体形式的展开

    设两波为：

    E~1=E10 eiϕ1 e−iωt,E~2=E20 eiϕ2 e−iωt\tilde{E}_1 = E_{10}\,e^{i\phi_1}\,e^{-i\omega t}, \quad \tilde{E}_2 = E_{20}\,e^{i\phi_2}\,e^{-i\omega t}E~1​=E10​eiϕ1​e−iωt,E~2​=E20​eiϕ2​e−iωt

    则：

    E~1∗E~2=E10E20 ei(ϕ2−ϕ1)\tilde{E}_1^* \tilde{E}_2 = E_{10}E_{20}\,e^{i(\phi_2 - \phi_1)}E~1∗​E~2​=E10​E20​ei(ϕ2​−ϕ1​) E~2∗E~1=E10E20 e−i(ϕ2−ϕ1)\tilde{E}_2^* \tilde{E}_1 = E_{10}E_{20}\,e^{-i(\phi_2 - \phi_1)}E~2∗​E~1​=E10​E20​e−i(ϕ2​−ϕ1​)

    取实部相加：

    E~1∗E~2+E~2∗E~1=2E10E20cos⁡(ϕ2−ϕ1)\tilde{E}_1^* \tilde{E}_2 + \tilde{E}_2^* \tilde{E}_1 = 2E_{10}E_{20}\cos(\phi_2 - \phi_1)E~1∗​E~2​+E~2∗​E~1​=2E10​E20​cos(ϕ2​−ϕ1​)

    若两电场矢量有夹角 α\alphaα，则标量积 E10E20E_{10}E_{20}E10​E20​ 应替换为 E⃗10⋅E⃗20=E10E20cos⁡α\vec{E}_{10}\cdot\vec{E}_{20} = E_{10}E_{20}\cos\alphaE10​⋅E20​=E10​E20​cosα。因此：

    Itot=I1+I2+2 E⃗10⋅E⃗20⋅cos⁡(ϕ2−ϕ1)I_{\text{tot}} = I_1 + I_2 + 2\,\vec{E}_{10}\cdot\vec{E}_{20}\cdot\cos(\phi_2 - \phi_1)Itot​=I1​+I2​+2E10​⋅E20​⋅cos(ϕ2​−ϕ1​)

    第三项即干涉项，它决定了干涉图样的形成。

    重要结论： 干涉是叠加原理的直接数学推论，并无任何额外假设。

    5. 相干条件（Conditions for Coherence）

    干涉项非零需要同时满足两个物理条件：

    条件一：偏振方向不垂直

    E⃗10⋅E⃗20≠0\vec{E}_{10}\cdot\vec{E}_{20} \neq 0E10​⋅E20​=0

    若两电场矢量正交（α=90∘\alpha = 90^\circα=90∘），则干涉项恒为零，无干涉现象。

    条件二：相位差稳定

    ⟨cos⁡(ϕ2−ϕ1)⟩t≠0\langle \cos(\phi_2 - \phi_1) \rangle_t \neq 0⟨cos(ϕ2​−ϕ1​)⟩t​=0

    对于普通光源，各点自发辐射的相位独立随机涨落，时间平均为零，不相干；激光具有固定相位关系，相干。

    6. 杨氏双缝实验（Young’s Double Slit Experiment）

    6.1 从波源到场

    点光源 S0S_0S0​ 发出的球面波经双缝 S1,S2S_1, S_2S1​,S2​ 再次衍射。在缝处可视作新的点波源，其场强按球面波衰减：

    E1=ASr1 eikr1,E2=ASr2 eikr2E_1 = \frac{A_S}{r_1}\,e^{ikr_1}, \quad E_2 = \frac{A_S}{r_2}\,e^{ikr_2}E1​=r1​AS​​eikr1​,E2​=r2​AS​​eikr2​

    其中 k=2π/λk = 2\pi/\lambdak=2π/λ 为波数。

    6.2 傍轴近似（Paraxial Approximation）

    当缝宽和缝间距 ddd 远小于到屏幕距离 DDD，且观察点 PPP 靠近轴线时：

    r1≈r2≈D,x2≪D2,d2≪D2r_1 \approx r_2 \approx D, \quad x^2 \ll D^2, \quad d^2 \ll D^2r1​≈r2​≈D,x2≪D2,d2≪D2

    此时振幅衰减可忽略（r1≈r2r_1 \approx r_2r1​≈r2​），但相位差不可忽略：

    E1=ASD eikr1,E2=ASD eikr2E_1 = \frac{A_S}{D}\,e^{ikr_1}, \quad E_2 = \frac{A_S}{D}\,e^{ikr_2}E1​=DAS​​eikr1​,E2​=DAS​​eikr2​

    6.3 几何关系

    从双缝到屏幕上 PPP 点，由三角形几何：

    r22=r12+d2+2dr1sin⁡θ≈D2+d2+2dDsin⁡θr_2^2 = r_1^2 + d^2 + 2dr_1\sin\theta \approx D^2 + d^2 + 2dD\sin\thetar22​=r12​+d2+2dr1​sinθ≈D2+d2+2dDsinθ

    6.5 明暗纹条件

    相长干涉（明纹）： cos⁡2(⋯ )=1\cos^2(\cdots) = 1cos2(⋯)=1，即 kΔr/2=mπk\Delta r/2 = m\pikΔr/2=mπ，故：

    7. 薄膜干涉与半波损失（Thin Film Interference & Phase Change）

    7.1 振幅分割机制

    光入射到厚度为 ddd 的薄膜时，在前表面和后表面分别发生反射。这两束反射光来自同一入射光经振幅分割，故必然相干（具有固定相位关系）。

    7.2 界面反射的相位跃变

    由菲涅尔公式，对 n1→n2n_1 \to n_2n1​→n2​ 的反射（n1<n2n_1 < n_2n1​<n2​，光密到光疏，注意原文符号约定）：

    r=n1−n2n2+n1r = \frac{n_1 - n_2}{n_2 + n_1}r=n2​+n1​n1​−n2​​

    对 n2→n1n_2 \to n_1n2​→n1​ 的反射：

    r′=n2−n1n2+n1=−rr' = \frac{n_2 - n_1}{n_2 + n_1} = -rr′=n2​+n1​n2​−n1​​=−r

    关键结论： 两式仅差一个负号，意味着若入射方向改变，反射系数变号，即产生 π\piπ 的相位跃变。这便是**半波损失（half-wave loss）**的数学表达。

    具体而言：

    • 光从光疏介质射向光密介质（n1<n2n_1 < n_2n1​<n2​）时，r<0r < 0r<0，相位跃变 π\piπ
    • 光从光密介质射向光疏介质（n1>n2n_1 > n_2n1​>n2​）时，r>0r > 0r>0，无相位跃变

    7.3 光程差计算

    考虑光以入射角 θi\theta_iθi​ 入射到折射率为 nnn 的薄膜。设两束反射光的光程差为 Δ\DeltaΔ：

    • 几何光程差： 上束光在上表面反射，下束光穿透前表面，在后表面反射，再穿透前表面返回。两束光在薄膜内经过的路径差为 2dcos⁡θt2d\cos\theta_t2dcosθt​（θt\theta_tθt​ 为折射角），几何光程为 2ndcos⁡θt2nd\cos\theta_t2ndcosθt​
    • 半波损失修正： 若两束反射中仅一束发生 π\piπ 相位跃变，则需额外计入 λ0/2\lambda_0/2λ0​/2 的光程差

    故总光程差：

    Δ=2ndcos⁡θt+{λ02,一束有半波损失0,两束均有或均无\Delta = 2nd\cos\theta_t + \begin{cases} \frac{\lambda_0}{2}, & \text{一束有半波损失} \\ 0, & \text{两束均有或均无} \end{cases}Δ=2ndcosθt​+{2λ0​​,0,​一束有半波损失两束均有或均无​

    7.4 干涉条件

    相位差 δ=k0Δ=2πλ0Δ\delta = k_0\Delta = \frac{2\pi}{\lambda_0}\Deltaδ=k0​Δ=λ0​2π​Δ。

    干涉极大： δ=2mπ\delta = 2m\piδ=2mπ（m=0,1,2,…m = 0, 1, 2, \dotsm=0,1,2,…），即：

    2ndcos⁡θt+λ02=mλ0⟹2ndcos⁡θt=(m−12)λ02nd\cos\theta_t + \frac{\lambda_0}{2} = m\lambda_0 \quad \Longrightarrow \quad 2nd\cos\theta_t = \left(m - \frac{1}{2}\right)\lambda_02ndcosθt​+2λ0​​=mλ0​⟹2ndcosθt​=(m−21​)λ0​

    注意： 干涉极大的条件取决于半波损失是否发生。日常所见的薄膜色彩（如肥皂泡）对应上述条件之一，需具体分析界面处的相位跃变。

    7.5 增透膜与增反膜

    • 增透膜： 取 2ndcos⁡θt=λ0/22nd\cos\theta_t = \lambda_0/22ndcosθt​=λ0​/2（对应一束有半波损失），即 d=λ0/(4ncos⁡θt)d = \lambda_0 / (4n\cos\theta_t)d=λ0​/(4ncosθt​)，使反射光相消、透射增强
    • 增反膜： 多层膜使多束反射同相叠加，增强反射

    8. 等厚干涉与等倾干涉

    8.1 等厚干涉（Equal Thickness）

    厚度 ddd 沿某方向线性变化（如劈形膜），条纹对应等厚线。入射角固定，条件：

    2ndcos⁡θt=mλ02nd\cos\theta_t = m\lambda_02ndcosθt​=mλ0​

    条纹平行于厚度突变边界。当 ddd 增大时，同一级次条纹移向厚度增加方向。

    8.2 等倾干涉（Equal Inclination）

    固定薄膜厚度 h0h_0h0​，改变入射角 θ\thetaθ，在透镜焦平面上形成同心圆环（牛顿环）。

    推导： 以平行光入射，固定 h0h_0h0​，第 mmm 级亮环满足：

    2nh0cos⁡θt=mλ02nh_0\cos\theta_t = m\lambda_02nh0​cosθt​=mλ0​

    9. 迈克尔逊干涉仪（Michelson Interferometer）

    9.1 光路结构

    迈克尔逊干涉仪的核心是分束器（beam splitter）——半镀银平板，对入射光 50% 反射、50% 透射。入射光被分成相互垂直的两束，分别经固定镜 M1M_1M1​ 和移动镜 M2M_2M2​ 反射后，沿原路返回并重新合并。

    9.2 光程差推导

    设分束器到两镜距离分别为 d1d_1d1​ 和 d2d_2d2​。光往返一次：

    臂1光程=2d1,臂2光程=2d2\text{臂1光程} = 2d_1, \quad \text{臂2光程} = 2d_2臂1光程=2d1​,臂2光程=2d2​

    总光程差：

    Δ=2d2−2d1=2(d2−d1)\Delta = 2d_2 - 2d_1 = 2(d_2 - d_1)Δ=2d2​−2d1​=2(d2​−d1​)

    乘以 2 是因为光既要去程（分束器→镜）又要有回程（镜→分束器）。

    9.3 干涉条纹

    • 若两臂光程严格相等（Δ=0\Delta = 0Δ=0），视场均匀（定域于无穷远的均匀视场）
    • 当 d2−d1=mλ/2d_2 - d_1 = m\lambda/2d2​−d1​=mλ/2 时，条纹对比度最佳
    • 移动镜每移动 λ/2\lambda/2λ/2，光程差变化 λ\lambdaλ，条纹移动一条（明→暗→明）

    9.4 应用

    1. 精密长度测量： 移动 Δd\Delta dΔd 时条纹变化数 NNN，则 Δd=N⋅λ/2\Delta d = N\cdot\lambda/2Δd=N⋅λ/2
    2. 光谱分析： 干涉图样的可见度（visibility）反映光源光谱结构
    3. 迈克耳逊-莫雷实验： 将干涉仪固定在转动基座上，预期不同方向光速差异产生 Δc⋅T\Delta c \cdot TΔc⋅T 的光程差变化（TTT 为光往返时间）。实验零结果否定以太假说，为狭义相对论奠基
