    《数据结构与算法》复习07：搜索树应用

    一、区间树

    区间树的概念来源于穿刺查询：在 x 轴上给定一组区间 S={si=[xi, xi′] ∣ 1≤i≤n}S=\{s_{i}=[x_{i},\,x_{i}']\,|\,1\leq i\leq n\}S={si​=[xi​,xi′​]∣1≤i≤n}，对于任何的点 qxq_{x}qx​，筛选出包含这个点的区间。

    将这些区间构造为区间树，查询时间是 O(r+log⁡n)O(r+\log n)O(r+logn)，其中 rrr 是输出查询结果的开销，log⁡n\log nlogn 是搜索深度。区间树的空间占用是 O(n)O(n)O(n)，将输入的每个区间各存了两份（左端点列表 / 右端点列表）。

    概念：

    以所有端点的中位点 xmidx_{mid}xmid​ 为界，将所有区间划分为三类：

    • 全部位于左半的区间 →\to→ 左子树；
    • 全部位于右半的区间 →\to→ 右子树；
    • 贯穿中位点的区间 →\to→ 节点。

    对于每个节点的查询，遍历找出 qxq_{x}qx​ 位于的区间（从外向内找是一种可以及时停止的找法），然后根据 qxq_{x}qx​ 和 mid\text{mid}mid 的大小比较来判断继续遍历哪个分支。

    二、线段树

    将所有区间的端点全部列出，这些端点会在数轴上分割出若干最小区间；用树的形式记录每个最小区间所承载的区间，即为线段树。

    在这个二叉树中，每个节点代表一段区间；根节点的区间是子节点区间的并集。若区间 xxx 被记录在这个节点里，则证明这个节点代表的区间能完全被区间 xxx 盖住。

    通过贪心地合并，每段区间最多只需要记录 O(log⁡n)O(\log n)O(logn) 次，空间复杂度是 O(nlog⁡n)O(n\log n)O(nlogn)。

    构造：

    首先对所有端点进行排序，由这些端点确定一棵二叉树；（自底而上、逐层合并，确定每个节点 vvv 的作用域 R(v)R(v)R(v).）

    然后在这个二叉树中存储 nnn 个区间的数据；这 nnn 个区间从上方自由落体，能稳稳接住区间的节点（即节点代表的区间能被落下来的区间盖住）即可记录这个区间。

    查询：

    只需要逐层向下查询，输出途中遇到的所有区间即可。

    三、范围树

    3.1 一维情况

    在一根数轴上有 nnn 个点。现在给出一个区间 [x1,x2][x_1, x_2][x1​,x2​]，问哪些点落在这个区间里？

    解：

    先把这 nnn 个点排好序。用 O(log⁡n)\mathcal{O}(\log n)O(logn) 的时间，快速定位到区间右端点 x2x_2x2​ 左侧最近的点（假设是点 7）。从点 7 开始顺藤摸瓜向左遍历（点 6、点 5），直到走出区间左端点 x1x_1x1​（假设到点 4 出界）。

    时间复杂度是 O(1+r+log⁡n)\mathcal{O}(1 + r + \log n)O(1+r+logn)，其中 rrr 是最终落在区间里的点的个数。

    3.2 二维情况

    给出一个矩形区域，要找出哪些点在这个矩形内。

    在二维时，点与点之间没有唯一的、有意义的次序。按照 xxx 轴排序， yyy 轴方向就是乱的；按照 yyy 轴排序，xxx 轴方向又是乱的。因此，简单的二分查找在这里无能为力。

    能不能拆成两次一维查询？不能；如果所有的点都密密麻麻地挤在 (x1,x2](x_1, x_2](x1​,x2​] 这个 xxx 轴区间里，那么 x 查询 完以后发现，几乎命中了所有的点（r1=Θ(n)r_1 = \Theta(n)r1​=Θ(n)）；继续进行 y-查询以后发现，其实最终的目标点只有可怜的几个（r=Θ(1)r = \Theta(1)r=Θ(1)）。浪费了 O(n)\mathcal{O}(n)O(n) 的时间。

    因此，需要借助 BBST……（不考）

    四、kd-树（k-dimensional tree）

    为利用 BBST 来支持二维的区域查询，可以递归地划分平面，并将分出来的矩形区域组织为一棵二叉树。约定每个矩形区域都是左闭右开、 下闭上开。

    4.1 kd-树的构建

    if (|P| < 2) return createLeaf(P);
    1. 当前点集 PPP 中的点数少于 2 个（即只有 1 个或 0 个点）时，停止切分，返回叶子节点。
    Direction = even(d) ? VERTICAL : HORIZONTAL;
    1. 当前树的深度 ddd 来交替选择切分方向。偶数层垂直切，奇数层水平切。
    Line = findMedian(P, root.SplitDirection); // O(n)
    1. 找出所有点坐标的中位数（本身是一个点），过这个点作切分线，从而确保划分出的左右两个子点集数量尽可能相等，保证最终建成的二叉树是平衡的。
    ( L, R ) = divide( P, Direction, Line );
Root->lc = buildKDTree( L, d+1 );
Root->rc = buildKDTree( R, d+1 );
return Root;

    4.2 四叉树 Quadtree

    用于对二维空间进行均匀的、层次化的递归分割。对每一层均分成四个象限（一般直接按照坐标均分，不考虑内容分布，否则叫 Point Quadtree）

    4.3 kd-树的查询

    4.3.1 基础算法

    要查询的问题是：在一个给定的、边界与坐标轴平行的矩形窗口内，包含了哪些数据点？

    方法是递归搜索：同样想象一块矩形板从空中掉下来，能稳稳接住的区域就可以直接开始统计，没有被完全覆盖住的区域就还要诉诸左子树和右子树来统计。

    4.3.2 Bounding Box

    每个节点 v 维护的不再是直线分割出的无缝大平面，而是其子树内所有点实际构成的最小外接矩形（Bounding Box）。这能有效减少搜索。

    4.4 kd-树的复杂度

    预处理时间：

    T(n)=2⋅T(n2)+O(n)=O(nlog⁡n).T(n)=2\cdot T\left( \frac{n}{2} \right)+O(n)=O(n\log n).T(n)=2⋅T(2n​)+O(n)=O(nlogn).

    树高：O(log⁡n)O(\log n)O(logn)

    空间：O(n)O(n)O(n).

    查询时间：O(n)O(\sqrt{ n })O(n​)。
