    《数据结构与算法》复习06：二叉搜索树

    一、二叉搜索树 BST 的概念

    在一个二叉搜索树中，元素一般是升序排列的；任何一个节点均不小于其左后代，也不大于其右后代。因此，BST 的中序遍历序列，必然是一个单调不减的序列。

    二、BST 的查找

    BST 的查找即二分查找；从根节点出发，逐步地缩小查找范围，直到发现目标或抵达空树（失败）。

    template <typename T, bool H> 
BNP<T> BST<T, H>::search( const T& e ) {
    for ( _p = nullptr, _x = _root; _x && (e != _x->data);  ) { 
        _p = _x; 
        _x = ( e < _p->data ) ? _p->lc : _p->rc;
    } 
    return _x; 
}

    三、BST 的插入

    标准 BST 插入的永远是叶子，因为插入枝是没有意义的。下面是一段搜寻正确的叶子节点并插入的算法：

    template <typename T, bool H> BNP<T> BST<T, H>::insert( const T& e, int h ) {
    if ( search( e ) ) return _p = _x;
    _x = new BinNode<T>( e, _p, nullptr, nullptr, h );
    ( _p ? ( *_x < *_p ? _p->lc : _p->rc ) : _root ) = _x;
    if ( H && _p ) 
        _p->updateHeightAbove();
    _size++; return _x;
}

    四、BST 的删除

    4.1 单分支删除

    如果待删除的节点是叶子节点 / 只有一个分支，那么可以直接将孙子节点上移：

    template <typename T, bool H> 
bool BST<T, H>::remove( const T& e ) {
    search( e ); if ( !_x ) return false;
    _r = _x->lc ? _x->lc : _x->rc;
    if ( _r ) _r->parent = _p;
    ( _p ? ( _p->lc == _x ? _p->lc : _p->rc ) : _root ) = _r;
    delete _x; _x = nullptr; _size--;
    if ( H && _p ) _p->updateHeightAbove();
    return true;
}

    4.2 双分支删除

    如果待删除的节点是双分支节点，那么为了不影响二分查找的逻辑，我们交换待删除结点 x 和大于它的第一个节点 x->succ（“李代桃僵”）。因为 x->succ 是大于 x 的第一个节点，这个节点一定没有左孩子，可以应用单分支删除。

    template <typename T, bool H> 
bool BST<T, H>::remove( const T& e ) {
    search( e ); if ( !_x ) return false;
    if ( _x->lc && _x->rc ) {
        BNP<T> s = eov(_x->rc); swap(_x->data, s->data);
        _x = s; _p = s->parent;
    }
    return true;
}

    五、二叉树的平衡

    5.1 二叉树的高度期望

    由 n 个互异节点随机组成的 BST，若总计 S(n) 棵，则若将这个树拆分成左子树 - 根节点 - 右子树分开看待：

    S(n)=∑k=1nS(k−1)⋅S(n−k)=catalan(n)=1n+1C2nn.S(n)=\sum_{k=1}^n S(k-1)\cdot S(n-k)=\text{catalan}(n)=\frac{1}{n+1}C_{2n}^n.S(n)=k=1∑n​S(k−1)⋅S(n−k)=catalan(n)=n+11​C2nn​.

    假定所有 BST 等概率出现，那么其高度期望是 Θ(n)\Theta(\sqrt{ n })Θ(n​)。这是不可接受的；

    我们希望二叉树高度的阶数等于 O(log⁡n)O(\log n)O(logn)。此时二叉树叫作平衡二叉树（BBST）。

    六、AVL 树

    6.1 平衡因子 Balance factor

    定义一个节点的平衡因子为：

    BalanceFactor(v)=height(v→lc)−height(v→rc)\text{BalanceFactor}(v)=\text{height}(v\to lc) - \text{height}(v\to rc)BalanceFactor(v)=height(v→lc)−height(v→rc)

    若每一个节点的平衡因子都 ≤1\leq{1}≤1，那么称这个树平衡。

    6.2 斐波那契树：最瘦的 AVL 树

    考察节点最少的高度为 h 的 AVL 树的节点个数：它一定有两个子树，这两个子树之间高度差至多是 1，因此

    S(h)=S(h−1)+S(h−2)+1S(h)=S(h-1)+S(h-2)+1S(h)=S(h−1)+S(h−2)+1 S(h)=fib(h+3)−1S(h)=\text{fib}(h+3)-1S(h)=fib(h+3)−1

    其内部结点的平衡因子均为 ±1\pm 1±1。

    6.3 AVL 的失衡

    插入：从祖父开始，每个祖先都有可能失衡，且可能同时失衡；

    删除：从父亲开始，每个祖先都有可能失衡，但任一时刻至多一个。

    6.4 AVL 树的插入复衡

    6.4.1 单旋：LL / RR

    名词定义：

    g：grandparent（第一个失衡点）

    p：parent 是 g 的更高的那棵子树，它的高度比 g 的另一棵子树高 2。

    v：vertex 是 p 的更高的那棵子树。它的高度比 p 的另一棵子树高 1。

    ================================ 状态 Y ================================

              (g)  <-- 执行 zag(g) 左旋
             /   \
            /     \
          [0]     (p)
                 /   \
                /     \
              [1]     (v)
                     /   \
                    /     \
                  [2]     [3]  <-- 插入后 2 和 3 恰好存在其一


                                   │
                                   │  zag(g) 左旋变换
                                   ▼


================================ 状态 Z ================================

                   (p)  <-- 成为新的局部根节点
                 /     \
                /       \
              (g)       (v)
             /   \     /   \
            /     \   /     \
          [0]    [1] [2]    [3]  <-- 旋转后复衡

    6.4.2 双旋：LR / RL

    如果按照原来的方法直接旋转，那么只会在 LR 和 RL 之间切换，无法做到树的平衡。因此我们需要旋转两次：

    ================================ 状态 X ================================


          (g)  
         /   \
        /     \
      [0]     (p)  <-- 执行 zig(p) 右旋
             /   \
            /     \
          (v)     [3]
         /   \
        /     \
      [1]     [2]  <-- 插入后 1 和 2 恰好存在其一


                               │
                               │  zig(p) 右旋变换
                               ▼


================================ 状态 Y ================================


          (g)  <-- 执行 zag(g) 左旋
         /   \
        /     \
      [0]     (v)
             /   \
            /     \
          [1]     (p)
                 /   \
                /     \
              [2]     [3]  <-- 第一次旋转后，黄节点形成斜向高差


                               │
                               │  zag(g) 左旋变换
                               ▼


================================ 状态 Z ================================


              (v)  <-- 成为新的局部根节点
             /   \
            /     \
          (g)     (p)
         /   \   /   \
        /     \ /     \
      [0]     [1] [2] [3]  <-- 旋转后复衡。

    6.4.3 代码实现

    局部子树复衡后，高度必然复原；所有祖先亦必复衡：累计至多会做 O(1)O(1)O(1) 次调整。

    #define AvlBalanced(x) ( ( -2 < BalFac(x) ) && ( BalFac(x) < 2 ) )

template <typename T> 
BNP<T> AVL<T>::insert( const T& e ) {
    BST::insert( e ); if ( _p == _x ) return _x;
    
    for ( BNP<T> g = _p; g; g = g->parent ) {
        if ( !AvlBalanced( g ) ) g = rotate( g );
        g->updateHeight();
        if ( 0 == BalFac( g ) ) break;
    }
    
    return _x;
}

    6.5 AVL 树的删除

    删除 AVL 树时，瞬间至多有一个失衡节点；但是复衡后，祖先仍然可能随之失衡，因为缺少元素。失衡可能继续向上传播，总计最多需要做 O(log⁡n)O(\log n)O(logn) 次调整。

    template <typename T> 
bool AVL<T>::remove( const T& e ) {
    if ( !BST<T>::remove( e ) ) return false;
    for ( BNP<T> g = _p; g; g = g->parent ) { 
        if ( !AvlBalanced( g ) ) g = rotate( g );
        g->updateHeight();
        if ( 0 != BalFac( g ) ) break; 
    } 
    return true; 
}

    其中， if ( 0 != BalFac( g ) ) break; 的判断逻辑是：

    • 如果这棵树的平衡因子本来是 1：剪掉长枝 / 短枝或将平衡因子更改为 2（ 会被旋转，平衡因子变回 0 ），或将平衡因子更改为 0 。在这两种情况下，树的高度都减小了 1，需要判断祖先。
    • 如果这棵树的平衡因子本来是 0：扣除元素后平衡因子是 ±1\pm1±1，但是不会导致树高减小，因而不会对祖先造成任何影响，可以直接退出。

    6.6 AVL 树的 3-4-2 重构

    3-4-2 重构是在现实的工业级 AVL 树实现中非常常见，甚至是写起来最不容易出错的标准范式。

    无论是哪种失衡情况（LL, RR, LR, RL），它们在本质上都是由于局部 3 个节点和 4 棵子树的相对高度失调引起的。然而，无论树的拓扑结构怎么变，它们在中序遍历中的相对顺序是不可改变的，即中序遍历必定夹在节点之间，呈现 T0<a<T1<b<T2<c<T3T_0 < a < T_1 < b < T_2 < c < T_3T0​<a<T1​<b<T2​<c<T3​。

    既然重平衡的最终目标是让这部分的局部高度最矮，那么目标拓扑结构只有一种：中间的 bbb 当根节点，aaa 当左孩子，ccc 当右孩子。然后把 4 棵子树按顺序平铺挂载在它们的膝下（T0,T1T_0, T_1T0​,T1​ 挂在 aaa 两侧，T2,T3T_2, T_3T2​,T3​ 挂在 ccc 两侧）。

    下述代码实现了寻找三个根节点并对其进行 3-4-2 重构的过程。

    template <typename T, bool H>
BNP<T> BST<T, H>::connect342( BNP<T> a, BNP<T> T1, BNP<T> b, BNP<T> T2, BNP<T> c ) {
    b->attachLc( a ); a->attachRc( T1 ); a->updateHeight();
    b->attachRc( c ); c->attachLc( T2 ); c->updateHeight();
    return b;
}

#define TallerChild(x) ( \
    Height( (x)->lc ) > Height( (x)->rc ) ? (x)->lc : ( \
    Height( (x)->lc ) < Height( (x)->rc ) ? (x)->rc : ( \
    ( (x)->parent && ( (x) == (x)->parent->lc ) ) ? (x)->lc : (x)->rc \
    ) \
    ) \
)

template <typename T, bool H> 
BNP<T> BST<T, H>::rotate( BNP<T> g ) {
    BNP<T> p = TallerChild(g); int TurnP = (p == g->rc);
    BNP<T> v = TallerChild(p); int TurnV = (v == p->rc);
    BNP<T> r = ( TurnP == TurnV ) ? p : v;
    ( FromParentTo(g) = r )->parent = g->parent;
    switch( ( TurnP << 1 ) | TurnV ) {
        case 0b00 : return connect342( v, v->rc, p, p->rc, g );
        case 0b01 : return connect342( p, v->lc, v, v->rc, g );
        case 0b10 : return connect342( g, v->lc, v, v->rc, p );
        default   : return connect342( g, p->lc, p, v->lc, v );
    }
}
