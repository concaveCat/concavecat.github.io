    变分法

    基本概念

    在多变微积分中，我们寻找的是一个最优的“点”（自变量数值）来最小化函数；而变分法寻找的是一条“最优曲线”（函数解析式）来最小化（或最大化）某个积分目标值。这种“输入一条曲线，输出一个标量”的积分映射在数学上被称为泛函。

    一、 变分法的基本数学模型

    最经典的单变量一阶变分问题可以表述为：寻找一个两次连续可微的未知函数 x(t)∈C2[a,b]x(t) \in C^2[a, b]x(t)∈C2[a,b]，它满足固定的边界约束条件：

    x(a)=A,x(b)=Bx(a) = A, \quad x(b) = Bx(a)=A,x(b)=B

    并使得以下形式的积分（泛函）取得极小值：

    I[x]=∫abL(t,x(t),x˙(t)) dtI[x] = \int_{a}^{b} L(t, x(t), \dot{x}(t)) \, \text{d}tI[x]=∫ab​L(t,x(t),x˙(t))dt

    其中：

    • ttt 为自变量（在物理中通常代表时间或一维空间坐标）。

    • x(t)x(t)x(t) 为待求的最优曲线。

    • x˙(t)=dxdt\dot{x}(t) = \frac{\text{d}x}{\text{d}t}x˙(t)=dtdx​ 为曲线的导数（一阶变化率，如速度）。

    • L(t,x,x˙)L(t, x, \dot{x})L(t,x,x˙) 称为拉格朗日量（Lagrangian），是一个关于三个自变量的三次连续可微多元函数。在纯微积分或数学分析的框架下， LLL 完全可以换成熟悉的函数符号 f(t,x,p)f(t, x, p)f(t,x,p)，只是在此处写作 LLL。

    二、 扰动法与第一变分的引入

    假设我们已经找到了这个问题的完美答案，即能够让泛函 I[x]I[x]I[x] 取得全局最小值的理想曲线 x(t)x(t)x(t)。

    为了利用传统微积分中“导数等于 0 确定极值”的成熟理论，数学家通过在理想答案上施加微小的“扰动”，将复杂的曲线寻找问题转化为单变量的极值求解。

    引入一族变分曲线：

    X(t,s)=x(t)+sy(t)X(t, s) = x(t) + s y(t)X(t,s)=x(t)+sy(t)

    其中：

    1. s∈Rs \in \mathbb{R}s∈R 是一个普通的标量实数参数，用于控制扰动的强弱。当 s=0s=0s=0 时，曲线完美退回最优解 x(t)x(t)x(t)。

    2. y(t)y(t)y(t) 是任意选择的、两次连续可微的扰动函数。

    3. 边界约束： 为了确保所有受扰动的曲线 X(t,s)X(t, s)X(t,s) 仍然从固定的起点 AAA 出发，并恰好落在固定的终点 BBB，扰动函数 y(t)y(t)y(t) 在两侧边界上必须严格为零：

      y(a)=0,y(b)=0y(a) = 0, \quad y(b) = 0y(a)=0,y(b)=0

    当我们将这族带扰动的曲线 X(t,s)X(t, s)X(t,s) 及其对 ttt 的导数 Xt(t,s)=x˙(t)+sy˙(t)X_t(t, s) = \dot{x}(t) + s \dot{y}(t)Xt​(t,s)=x˙(t)+sy˙​(t) 代入泛函积分中时，原本对未知函数的积分便转化为了一个关于普通实数变量 sss 的标量函数 F(s)F(s)F(s)：

    F(s)=∫abL(t,X(t,s),∂X∂t(t,s)) dt=∫abL(t,x(t)+sy(t),x˙(t)+sy˙(t)) dtF(s) = \int_{a}^{b} L\left(t, X(t, s), \frac{\partial X}{\partial t}(t, s)\right) \, \text{d}t = \int_{a}^{b} L(t, x(t) + s y(t), \dot{x}(t) + s \dot{y}(t)) \, \text{d}tF(s)=∫ab​L(t,X(t,s),∂t∂X​(t,s))dt=∫ab​L(t,x(t)+sy(t),x˙(t)+sy˙​(t))dt

    由于我们事先假设 s=0s = 0s=0（即无扰动）时对应的曲线 x(t)x(t)x(t) 是最完美的极小值解，因此多元标量函数 F(s)F(s)F(s) 必然在 s=0s = 0s=0 处取得极小值。由一元微积分的极值必要条件可知，其导数必为 0：

    F′(0)=dFds∣s=0=0F'(0) = \left. \frac{\text{d}F}{\text{d}s} \right|_{s=0} = 0F′(0)=dsdF​​s=0​=0

    这个导数 F′(0)F'(0)F′(0) 在变分学中被称为泛函的第一变分，通常记作 δI\delta IδI。

    三、 欧拉-拉格朗日方程的严格推导

    下面我们通过对 F(s)F(s)F(s) 严格求导来导出变分法的核心控制方程。

    第一步：积分号内求导（莱布尼茨法则）

    由于积分区间 [a,b][a, b][a,b] 是固定常数，且拉格朗日量 LLL 连续可微，我们可以合法地将关于参数 sss 的求导符号移入积分号内部：

    dFds=∫ab∂∂sL(t,X(t,s),Xt(t,s)) dt\frac{\text{d}F}{\text{d}s} = \int_{a}^{b} \frac{\partial}{\partial s} L\left(t, X(t, s), X_t(t, s)\right) \, \text{d}tdsdF​=∫ab​∂s∂​L(t,X(t,s),Xt​(t,s))dt

    第二步：应用多元链式法则

    注意到拉格朗日量 LLL 的第二参数位置为 XXX，第三参数位置为 XtX_tXt​，而它们都显含变量 sss。应用全微分链式法则展开：

    ∂∂sL(t,X(t,s),Xt(t,s))=∂L∂X∂X∂s+∂L∂Xt∂Xt∂s\frac{\partial}{\partial s} L\left(t, X(t, s), X_t(t, s)\right) = \frac{\partial L}{\partial X} \frac{\partial X}{\partial s} + \frac{\partial L}{\partial X_t} \frac{\partial X_t}{\partial s}∂s∂​L(t,X(t,s),Xt​(t,s))=∂X∂L​∂s∂X​+∂Xt​∂L​∂s∂Xt​​

    根据变分族的构造公式 X(t,s)=x(t)+sy(t)X(t, s) = x(t) + s y(t)X(t,s)=x(t)+sy(t)，直接对 sss 求偏导可得：

    ∂X∂s=y(t),∂Xt∂s=∂∂s(x˙(t)+sy˙(t))=y˙(t)\frac{\partial X}{\partial s} = y(t), \quad \frac{\partial X_t}{\partial s} = \frac{\partial}{\partial s}(\dot{x}(t) + s \dot{y}(t)) = \dot{y}(t)∂s∂X​=y(t),∂s∂Xt​​=∂s∂​(x˙(t)+sy˙​(t))=y˙​(t)

    将这两个偏导数项代回积分表达式中：

    dFds=∫ab[∂L∂Xy(t)+∂L∂Xty˙(t)] dt\frac{\text{d}F}{\text{d}s} = \int_{a}^{b} \left[ \frac{\partial L}{\partial X} y(t) + \frac{\partial L}{\partial X_t} \dot{y}(t) \right] \, \text{d}tdsdF​=∫ab​[∂X∂L​y(t)+∂Xt​∂L​y˙​(t)]dt

    第三步：令 s=0s = 0s=0 锁定极值状态

    当参数 s=0s = 0s=0 时，扰动完全消失，X(t,0)=x(t)X(t, 0) = x(t)X(t,0)=x(t) 且 Xt(t,0)=x˙(t)X_t(t, 0) = \dot{x}(t)Xt​(t,0)=x˙(t)。此时，偏导数 ∂L∂X\frac{\partial L}{\partial X}∂X∂L​ 和 ∂L∂Xt\frac{\partial L}{\partial X_t}∂Xt​∂L​ 变回理想最优路径上的偏导数，通常简写为 LxL_xLx​ 和 Lx˙L_{\dot{x}}Lx˙​。代入极值条件 F′(0)=0F'(0)=0F′(0)=0 得到：

    F′(0)=∫ab[Lx(t,x,x˙)y(t)+Lx˙(t,x,x˙)y˙(t)] dt=0F'(0) = \int_{a}^{b} \left[ L_x(t, x, \dot{x}) y(t) + L_{\dot{x}}(t, x, \dot{x}) \dot{y}(t) \right] \, \text{d}t = 0F′(0)=∫ab​[Lx​(t,x,x˙)y(t)+Lx˙​(t,x,x˙)y˙​(t)]dt=0

    第四步：运用分部积分消去 y˙(t)\dot{y}(t)y˙​(t)

    在上式中，第二项含有扰动函数的导数 y˙(t)\dot{y}(t)y˙​(t)。为了能将未知项 y(t)y(t)y(t) 整体作为公因式提出来，我们对第二项应用分部积分法：

    设 u=Lx˙(t,x,x˙)u = L_{\dot{x}}(t, x, \dot{x})u=Lx˙​(t,x,x˙)，dv=y˙(t) dt=dy(t)\text{d}v = \dot{y}(t)\,\text{d}t = \text{d}y(t)dv=y˙​(t)dt=dy(t)，则有：

    ∫abLx˙(t,x,x˙)y˙(t) dt=[Lx˙(t,x,x˙)y(t)]ab−∫abddt(Lx˙(t,x,x˙))y(t) dt\int_{a}^{b} L_{\dot{x}}(t, x, \dot{x}) \dot{y}(t) \, \text{d}t = \left[ L_{\dot{x}}(t, x, \dot{x}) y(t) \right]_{a}^{b} - \int_{a}^{b} \frac{\text{d}}{\text{d}t} \left( L_{\dot{x}}(t, x, \dot{x}) \right) y(t) \, \text{d}t∫ab​Lx˙​(t,x,x˙)y˙​(t)dt=[Lx˙​(t,x,x˙)y(t)]ab​−∫ab​dtd​(Lx˙​(t,x,x˙))y(t)dt

    由于前文设定的物理边界条件规定扰动在端点处必须为零（y(a)=0,y(b)=0y(a) = 0, y(b) = 0y(a)=0,y(b)=0），因此第一项边界项带入后完全消去：

    [Lx˙(t,x,x˙)y(t)]ab=Lx˙(b,x(b),x˙(b))⋅0−Lx˙(a,x(a),x˙(a))⋅0=0\left[ L_{\dot{x}}(t, x, \dot{x}) y(t) \right]_{a}^{b} = L_{\dot{x}}(b, x(b), \dot{x}(b)) \cdot 0 - L_{\dot{x}}(a, x(a), \dot{x}(a)) \cdot 0 = 0[Lx˙​(t,x,x˙)y(t)]ab​=Lx˙​(b,x(b),x˙(b))⋅0−Lx˙​(a,x(a),x˙(a))⋅0=0

    积分项成功化简为：

    ∫abLx˙(t,x,x˙)y˙(t) dt=−∫abddt(Lx˙(t,x,x˙))y(t) dt\int_{a}^{b} L_{\dot{x}}(t, x, \dot{x}) \dot{y}(t) \, \text{d}t = - \int_{a}^{b} \frac{\text{d}}{\text{d}t} \left( L_{\dot{x}}(t, x, \dot{x}) \right) y(t) \, \text{d}t∫ab​Lx˙​(t,x,x˙)y˙​(t)dt=−∫ab​dtd​(Lx˙​(t,x,x˙))y(t)dt

    第五步：合并积分并应用变分法基本引理

    将分部积分后的项重新代回 F′(0)F'(0)F′(0)，合并同类项并提取公因式 y(t)y(t)y(t)：

    F′(0)=∫ab[Lx(t,x,x˙)−ddtLx˙(t,x,x˙)]y(t) dt=0F'(0) = \int_{a}^{b} \left[ L_x(t, x, \dot{x}) - \frac{\text{d}}{\text{d}t} L_{\dot{x}}(t, x, \dot{x}) \right] y(t) \, \text{d}t = 0F′(0)=∫ab​[Lx​(t,x,x˙)−dtd​Lx˙​(t,x,x˙)]y(t)dt=0

    此时需要引入核心的变分法基本引理：

    若一个连续函数 M(t)M(t)M(t) 满足：对于区间 [a,b][a, b][a,b] 上任意给定的、在端点为零（y(a)=y(b)=0y(a)=y(b)=0y(a)=y(b)=0）的连续可微扰动函数 y(t)y(t)y(t)，都有积分 ∫abM(t)y(t) dt=0\int_{a}^{b} M(t) y(t) \, \text{d}t = 0∫ab​M(t)y(t)dt=0 恒成立，则在整个区间上必有 M(t)≡0M(t) \equiv 0M(t)≡0。

    因为扰动函数 y(t)y(t)y(t) 具有完全的随机性和任意性，要想让整个积分对任何 y(t)y(t)y(t) 都绝对等于 0，中括号内部的解析式本身就必须处处为 0。从而我们推导出了最著名的欧拉-拉格朗日方程：

    Lx−ddtLx˙=0L_x - \frac{\text{d}}{\text{d}t} L_{\dot{x}} = 0Lx​−dtd​Lx˙​=0

    展开其中的全导数项 ddt\frac{\text{d}}{\text{d}t}dtd​（注意 Lx˙L_{\dot{x}}Lx˙​ 的自变量包含 t,x,x˙t, x, \dot{x}t,x,x˙）：

    ddtLx˙=Lx˙t+Lx˙xx˙+Lx˙x˙x¨\frac{\text{d}}{\text{d}t} L_{\dot{x}} = L_{\dot{x}t} + L_{\dot{x}x}\dot{x} + L_{\dot{x}\dot{x}}\ddot{x}dtd​Lx˙​=Lx˙t​+Lx˙x​x˙+Lx˙x˙​x¨

    可以看到，欧拉-拉格朗日方程在本质上是一个关于未知路径 x(t)x(t)x(t) 的二阶常微分方程（ODE）。

    四、 多维情形下的扩展

    若待求的目标不是空间中的一维曲线，而是一条多维空间轨迹 x(t)=(x1(t),x2(t),…,xn(t))T∈Rn\mathbf{x}(t) = (x_1(t), x_2(t), \dots, x_n(t))^T \in \mathbb{R}^nx(t)=(x1​(t),x2​(t),…,xn​(t))T∈Rn，其对应的泛函为：

    五、 降阶特殊情形与数学严格证明

    由于欧拉-拉格朗日方程通常是高难度的二阶微分方程，在实际物理或几何应用中，如果拉格朗日量 LLL 缺少某些自变量，我们可以利用守恒律直接将其降阶为一阶微分方程（积分第一不变量）。

    情形 1：系统不显含自变量 ttt（即 L=L(x,x˙)L = L(x, \dot{x})L=L(x,x˙)）

    这在物理上对应着系统在时间轴上具有平移对称性，意味着系统的总能量守恒。

    数学证明：

    我们尝试对当前的拉格朗日量 L(x,x˙)L(x, \dot{x})L(x,x˙) 直接关于时间 ttt 求全导数：

    dLdt=∂L∂xdxdt+∂L∂x˙dx˙dt=Lxx˙+Lx˙x¨\frac{\text{d}L}{\text{d}t} = \frac{\partial L}{\partial x} \frac{\text{d}x}{\text{d}t} + \frac{\partial L}{\partial \dot{x}} \frac{\text{d}\dot{x}}{\text{d}t} = L_x \dot{x} + L_{\dot{x}} \ddot{x}dtdL​=∂x∂L​dtdx​+∂x˙∂L​dtdx˙​=Lx​x˙+Lx˙​x¨

    dLdt=(ddtLx˙)x˙+Lx˙x¨\frac{\text{d}L}{\text{d}t} = \left( \frac{\text{d}}{\text{d}t} L_{\dot{x}} \right) \dot{x} + L_{\dot{x}} \ddot{x}dtdL​=(dtd​Lx˙​)x˙+Lx˙​x¨

    观察等式的右侧，根据乘积的求导法则（(uv)′=u′v+uv′(uv)' = u'v + uv'(uv)′=u′v+uv′），它刚好可以合并为两项乘积的整体导数：

    (ddtLx˙)x˙+Lx˙x¨=ddt(Lx˙x˙)\left( \frac{\text{d}}{\text{d}t} L_{\dot{x}} \right) \dot{x} + L_{\dot{x}} \ddot{x} = \frac{\text{d}}{\text{d}t} \left( L_{\dot{x}} \dot{x} \right)(dtd​Lx˙​)x˙+Lx˙​x¨=dtd​(Lx˙​x˙)

    dLdt=ddt(Lx˙x˙)  ⟹  ddt(L−x˙Lx˙)=0\frac{\text{d}L}{\text{d}t} = \frac{\text{d}}{\text{d}t} \left( L_{\dot{x}} \dot{x} \right) \implies \frac{\text{d}}{\text{d}t} \left( L - \dot{x} L_{\dot{x}} \right) = 0dtdL​=dtd​(Lx˙​x˙)⟹dtd​(L−x˙Lx˙​)=0

    两边同时对 ttt 进行积分，即可得到经典的 Beltrami 恒等式：

    L−x˙Lx˙=C(常数 C)L - \dot{x} L_{\dot{x}} = C \quad (\text{常数 } C)L−x˙Lx˙​=C(常数 C)

    这成功将一个二阶 ODE 降阶为了更易求解的一阶 ODE。

    情形 2：系统不显含未知函数 xxx（即 L=L(t,x˙)L = L(t, \dot{x})L=L(t,x˙)）

    这在物理上对应着系统在空间位置上具有平移对称性，意味着系统的广义动量守恒。
