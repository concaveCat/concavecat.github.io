    第二类曲面积分

    一、定向曲面

    1. 超曲面 (Hypersurface)

    在 NNN 维欧几里得空间 RN\mathbb{R}^NRN 中，一个 N−1N-1N−1 维的曲面 Σ\SigmaΣ 被称为超曲面。

    • 直观理解：超曲面的维度比它所在的宿主空间少 1 维。例如，R3\mathbb{R}^3R3 中的 2 维球面、R2\mathbb{R}^2R2 中的 1 维曲线。

    2. 可定向性 (Orientability)

    如果超曲面 Σ\SigmaΣ 上存在一个连续的单位法向量场 n:Σ→RN\mathbf{n}: \Sigma \rightarrow \mathbb{R}^Nn:Σ→RN，则称该超曲面是可定向的 (Orientable)。

    • 此时，有序对 (Σ,n)(\Sigma, \mathbf{n})(Σ,n) 被称为一个有向曲面 (Oriented Surface)。

    • 物理意义：这意味着曲面存在一致的“正面”和“反面”（或“内侧”与“外侧”），且在这两个方向中我们选定了一个作为正向。

    3. 例一：超平面 (Hyperplane)

    考虑 RN\mathbb{R}^NRN 中的超平面，其隐函数方程为：

    二、定向曲面的判定条件

    1. 可微函数的等值集是定向曲面

    设 F:RN→RF: \mathbb{R}^N \rightarrow \mathbb{R}F:RN→R 是一个可微函数。若 000 是 FFF 的一个正则值 (Regular Value)，且等值集 Σ=F−1(0)={x∈RN∣F(x)=0}\Sigma = F^{-1}(0) = \{\mathbf{x} \in \mathbb{R}^N \mid F(\mathbf{x}) = 0\}Σ=F−1(0)={x∈RN∣F(x)=0} 非空，则 Σ\SigmaΣ 是一个可定向的超曲面。

    首先，∀x∈Σ,grad F(x)≠0  ⟹  Σ\forall \mathbf{x} \in \Sigma, \text{grad } F(\mathbf{x}) \neq \mathbf{0} \implies \Sigma∀x∈Σ,grad F(x)=0⟹Σ 是曲面。

    详细推导：

    1. 梯度向量表示为 grad F(x)=(∂F∂x1,∂F∂x2,…,∂F∂xN)T\text{grad } F(\mathbf{x}) = \left( \frac{\partial F}{\partial x^1}, \frac{\partial F}{\partial x^2}, \dots, \frac{\partial F}{\partial x^N} \right)^Tgrad F(x)=(∂x1∂F​,∂x2∂F​,…,∂xN∂F​)T。

    2. 因为 grad F(x)≠0\text{grad } F(\mathbf{x}) \neq \mathbf{0}grad F(x)=0，这意味着在任意点 x0∈Σ\mathbf{x}_0 \in \Sigmax0​∈Σ 处，至少存在一个偏导数不为 0。不妨设 ∂F∂xN(x0)≠0\frac{\partial F}{\partial x^N}(\mathbf{x}_0) \neq 0∂xN∂F​(x0​)=0。

    3. 根据隐函数定理 (Implicit Function Theorem)，在点 x0\mathbf{x}_0x0​ 的一个局部邻域内，方程 F(x1,…,xN−1,xN)=0F(x^1, \dots, x^{N-1}, x^N) = 0F(x1,…,xN−1,xN)=0 可以唯一地解出最后一个坐标：

      xN=f(x1,…,xN−1)x^N = f(x^1, \dots, x^{N-1})xN=f(x1,…,xN−1)

      其中 fff 是一个可微函数。

    4. 这说明在任意一点的局部，Σ\SigmaΣ 都可以表示为一个 N−1N-1N−1 维图形的函数图像（即局部坐标图）。因此，Σ\SigmaΣ 是一个光滑的 N−1N-1N−1 维超曲面。

    其次，Σ\SigmaΣ 必然是“可定向”的。

    详细推导：

    根据可定向性的定义，我们需要在 Σ\SigmaΣ 全局构造一个连续的单位法向量场 n(x)\mathbf{n}(\mathbf{x})n(x)。

    直接定义向量场：

    n(x)=grad F(x)∥grad F(x)∥\mathbf{n}(\mathbf{x}) = \frac{\text{grad } F(\mathbf{x})}{\|\text{grad } F(\mathbf{x})\|}n(x)=∥grad F(x)∥grad F(x)​

    因为分子 grad F(x)\text{grad } F(\mathbf{x})grad F(x) 连续且分母 ∥grad F(x)∥\|\text{grad } F(\mathbf{x})\|∥grad F(x)∥ 连续且处处正，所以两者的商 n(x)\mathbf{n}(\mathbf{x})n(x) 在整个 Σ\SigmaΣ 上也是完全连续的。由于找到了这个在全球（整个曲面）范围内都连续的单位法向量场，根据定义，Σ\SigmaΣ 必然是可定向曲面。

    2. 可微函数的图像是一个可定向曲面

    设 f:D⊂Rm→Rf: D \subset \mathbb{R}^m \rightarrow \mathbb{R}f:D⊂Rm→R 是一个可微函数，其图像定义为 Rm+1\mathbb{R}^{m+1}Rm+1 中的点集：

    3. 正则参数曲面是一个可定向曲面

    3.1. 核心定义：正则参数曲面

    设 Σ\SigmaΣ 是 Rm+1\mathbb{R}^{m+1}Rm+1 中的超曲面，它由映射 x:D⊂Rm→Rm+1\mathbf{x}: D \subset \mathbb{R}^m \rightarrow \mathbb{R}^{m+1}x:D⊂Rm→Rm+1 参数化表示：

    Σ={x(t1,…,tm)∣(t1,…,tm)∈D}\Sigma = \{ \mathbf{x}(t^1, \dots, t^m) \mid (t^1, \dots, t^m) \in D \}Σ={x(t1,…,tm)∣(t1,…,tm)∈D}

    要让它成为一个正则参数曲面，必须满足两个核心条件：

    1. 单射（Injective）：映射 x\mathbf{x}x 是单射（保证曲面不自交）。

    2. 正则性（Regularity）：雅可比矩阵（Jacobian matrix） ∂(x1,…,xm+1)∂(t1,…,tm)\frac{\partial(x^1, \dots, x^{m+1})}{\partial(t^1, \dots, t^m)}∂(t1,…,tm)∂(x1,…,xm+1)​ 是满列秩的。

      • 几何意义：这意味着在曲面的任何一点上，偏导数切向量组 {x1,x2,…,xm}\{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_m\}{x1​,x2​,…,xm​}（其中 xk=∂x∂tk\mathbf{x}_k = \frac{\partial \mathbf{x}}{\partial t_k}xk​=∂tk​∂x​）是线性无关的。它们张成了曲面在该点的切空间 TxΣT_{\mathbf{x}}\SigmaTx​Σ。
