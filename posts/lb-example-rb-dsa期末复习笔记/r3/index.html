    《数据结构与算法》复习03：列表

    一、列表构造

    	 (succ)       (succ)
[-1]  ---->  [0]  ---->  [2]    --- ... --->  [n-1] ---->  [n]
head  <---- first <---- second  <-- ... ----  last  <----  tail
	 (pred)       (pred)

    head 和 tail 实际上是充当哨兵的作用，实际上不存储数据。

    因此，列表的构造如下：

    template <typename T>
class List {
protected:
	int _size; 
	Node<T> head, tail;
public:
	...
};

    初始化逻辑：

    head = new ListNode<T>;
tail = new ListNode<T>;
head->succ = tail;
tail->pred = head;
_size = 0;

    二、列表的访问

    列表的访问就是按照元素顺序逐个向后查找，时间复杂度 O(n)O(n)O(n)。

    template <typename T> List::operator+ ( int r ) {
	for ( p = this; ; p = p->succ, r-- )
		if ( r == 0 ) 
			return p;
}
template <typename T> List::operator[] ( int r ) {
	return *first() + r;
}

    三、列表的插入

    列表的插入分为三步：

    1. 创建新节点；
    2. 为新节点找好上下家；
    3. 让上下家对接新节点。
    template <typename T> List::insertPred( const T& e ) {
	x = new ListNode ( e, pred, this );
	pred->succ = x;
	pred = x;
	return x;
}

    7.1 设置哨兵

    这里采用一种设置哨兵的方法：用待查找元素（eee）顶掉队首元素（cur\text{cur}cur），用 eee 不断地和 cur→succ\text{cur}\to\text{succ}cur→succ 比较。

    • 如果找到相等元素则终止循环；
    • 如果比较到最后一位还是没有找到相等元素（cur≠e\text{cur}\neq ecur=e），那么就是没有找到。

    八、列表的去重

    8.1 遍历法

    template <typename T> 
List<T>::find( ListNodePosi<T> h, const T& e, ListNodePosi<T> t ) const {
    T bak = t->data; 
    t->data = e;     
    while ( e != ( h = h->succ )->data ); 
    t->data = bak; 
    return ( h == t ) ? nullptr : h; 
    
} //find: O(n)

    最坏情况就是 O(n2)O(n^{2})O(n2)，因为删除只需要 O(1)O(1)O(1)，时间消耗全部在于遍历。

    8.2 有序数组去重

    void uniquify() {
	if ( _size < 2 ) return;
	for ( p = first(), q = p->succ; q != tail; q = p->succ ) {
		if ( p->data != q->data )
			p = q;
		else 
			remove(q);
	}
}

    因为是有序的，只需要遍历一次，时间复杂度为 O(n)O(n)O(n)。

    九、选择排序

    9.1 起泡排序的痛点

    在起泡排序中，对于每个最大元素，寻找到这个元素需要 O(n)O(n)O(n) 时间，将这个最大元素置换到最顶层也需要 O(n)O(n)O(n) 时间。不过显然，置换到顶层的时间完全可以省去。

    如果直接用 swap 将最大元素置换到最顶层，我们就得到了选择排序。

    9.2 基础选择排序

    void SelectionSort( head, tail ) {
	for ( ; head->succ != t; t = t->pred )
		swap( getMax( h, t )->data, t->pred->data );
}

    这份示例代码中，数组被连续从后向前遍历，每个被遍历到的位置都会在它之前寻求最大值顶替自己。经过一轮遍历数组就位。

    int getMax( head, tail ) {
	for ( x = tail = tail->pred; x != head; x = x->pred )
		if ( tail->data < x->data )
			tail = x;
	return tail;
}

    但是如果考察时间复杂度，就会发现对于任何序列，时间复杂度仍然是 O(n2)O(n^{2})O(n2)；这是不可接受的。我们有两种改进思路：

    • getMax 函数的时间复杂度可以被改进为 O(log⁡n)O(\log n)O(logn) ：选择 二叉堆 替代线性数据结构，选择排序就会直接变成 O(nlog⁡n)O(n\log n)O(nlogn) 的堆排序。
    • swap 的动作可以被精简；如果元素碰巧在正确的位置，利用局部有序性，可以避免很多下滤操作。下面考察这种情况。

    9.3 轮换

    任何一个无重复元素的数组，其当前状态相对于最终有序状态的映射，都可以唯一分解为若干个互不相交的“环”（轮换）。

    只要发生有效交换，原有的环就会分裂出一个长度为 1 的“已就位小环”，剩下的环长度减 1。整个数组的总环数（轮换数） kkk 加 1。当数组排序完成，环的数量应当达到最大值 nnn。

    因此，对于所有的交换函数，其“交换”（写）动作数的理论下界是 n−kn-kn−k。 （Cycle Sort实现了这种理想，但是以 O(n2)O(n^{2})O(n2) 时间复杂度为代价）当然，为了找出最优的交换顺序，我们仍需 O(n2)O(n^{2})O(n2) 时间来对所有数据进行排序，这同样是不可忍受的。

    我们好奇原先有多少次 swap 是多余的；即，对每一个位置，它是局部最大值的期望。不难发现，结果是 1+12+13+⋯=log⁡n1+\frac{1}{2}+\frac{1}{3}+\dots=\log n1+21​+31​+⋯=logn。相对 n2n^{2}n2 显然不是很多。

    十、插入排序

    插入排序好比洗牌。每次将牌堆中的牌取出，按照顺序插到洗好的牌堆里面，即为插入排序。

    void insertionSort ( head, tail ) {
	for ( r = head->succ, s = r->succ; r != tail; r = s, s = r->succ ) 
		r->insert( search( head, r->data, r ) );
}

    插入排序的时间复杂度介于 O(n)O(n)O(n) 和 O(n2)O(n^{2})O(n2)，取决于插入的幸运程度。

    插入排序的最大优势源于其“在线”：数据部分就绪，即可开始计算。

    十一、归并排序求逆序对

    蛮力求逆序对的方法总需要 O(n2)O(n^{2})O(n2) 的时间；但是寄生于归并排序的框架，则只需要 O(nlog⁡n)O(n\log n)O(nlogn) 的时间即可。

    考察被剖分成两半的数组：

    • 若逆序对全部位于左半区，则交给下一层递归来处理。
    • 若逆序对全部位于右半区，则交给下一层递归来处理。
    • 若逆序对横跨中间，则交给 merge 函数来处理：
    		   ▊
	   ▊   ▊                 ▊   ▊
	   ▊   ▊             ▊   ▊   ▊
▁▁▁▊▁▁▁▊▁▁▁▊▁▁▁▁▁▁▁▁▁▊▁▁▁▊▁▁▁▊▁▁▁▊▁▁▁
   1   2   3         4   5   6   7

    当 2 在被塞入已排序数组时，它观察右半区已经被塞入排序数组的元素，发现 4,5 已经塞入，则它们一定比自己矮，逆序数+2+2+2。以此类推即可获取逆序数。
