    《数据结构与算法》复习02：向量

    一、数组和向量

    向量是数组的抽象与泛化，由一组元素按线性次序封装而成。各元素与[0,n)[0,n)[0,n)内的秩（rank）一一对应。

	T* _elem; //数据区

	int _size; //规模
protected:
	/* ... 内部接口 */
public:
	/* ... 开放接口 */
}; //Vector

    二、插入和删除

    2.1 插入

    在向量中第 kkk 位插入元素，需要经过三步：（O(n−k)O(n-k)O(n−k)）

    1. 如果空间不够，那么需要扩容；
    2. 将 [k,n][k,n][k,n] 位元素全部后移一位；
    3. 插入第 kkk 位元素。

    2.2 删除

    删除向量中第 kkk 位的元素，需要经过一步：（O(n−k)O(n-k)O(n−k)）

    1. 将 [k+1,n][k+1,n][k+1,n] 位元素全部左移一位，覆盖原第 kkk 位元素。

    三、空间管理

    首先，我们定义装填因子 λ=sizecapacity\lambda = \frac{\text{size}}{\text{capacity}}λ=capacitysize​。空间管理包含两种操作：

    1. 在 λ=100%\lambda=100\%λ=100% 时扩容；
    2. 在 λ≪50%\lambda\ll 50\%λ≪50% 时收缩。

    在实际情况下，我们应当保持 25%<λ<100%25\%<\lambda<100\%25%<λ<100%。

    3.1 扩容操作

    1. 申请一段新的空间；（简化下，每次扩容空间大小加倍）
    2. 将 nnn 个元素 copy 到新的空间

    3.2 均摊分析扩容耗费时间

    对每次容量加倍，都需要 O(n)O(n)O(n) 次计算来搬运数据，但是新扩展出的容量又可以容纳 nnn 个数据，摊还至每一个元素，时间复杂度是 O(1)O(1)O(1)。

    四、去重

    我们在这里假设向量原先是排序过的。

    4.1 原位删除：低效算法

    从前向后遍历，逐一比对相邻的 k−1k-1k−1 和 kkk 个元素，如果相等则删除元素。时间复杂度是 O(n2)O(n^{2})O(n2) （O(n)O(n)O(n) 遍历，O(n)O(n)O(n) 删除）。

    4.2 新建向量：高效算法

    从前向后遍历，取出不同的元素，放入新的向量中。时间复杂度 O(n)O(n)O(n)。

    五、二分查找

    5.1 版本A

    5.1.1 代码叙述

    template <typename T> int binSearch( T* S, const T& e, int lo, int hi ) {
    while ( lo < hi ) { //每步迭代三个分支，最多两次比较
        int mi = (lo + hi) / 2; //以中位数为轴点，区间宽度折半
        if ( e < S[mi] ) hi = mi; //深入前缀[lo, mi)
        else if ( S[mi] < e ) lo = mi + 1; //深入后缀(mi, hi)
        else return mi; //命中，收工：有多个e时，不能保证返回秩最大者
    } //出口时lo==hi
    return -1; //失败
} //但-1不能指示失败的位置

    5.1.2 逻辑过程

    在 while ( lo < hi ) 循环内部，算法通过两次比较将当前的搜索范围划分为三种情况（三个分支）：

    • 分支一 (e < S[mi])：如果要查找的元素 e 小于中位数 S[mi]，说明 e 只可能在左侧区间。因此将右边界更新为 hi = mi，下一步在 [lo, mi) 中继续查找。

    • 分支二 (S[mi] < e)：如果 S[mi] 小于 e，说明 e 只可能在右侧区间。因此将左边界更新为 lo = mi + 1，下一步在 [mi + 1, hi) 中继续查找。

    • 分支三 (else)：如果以上两个条件都不满足，说明 S[mi] == e，即成功命中目标，直接返回当前位置的索引（秩）mi。

    5.1.3 缺点

    • 向左深入只需要 1 次比较，而向右深入或命中需要 2 次比较。 在最坏情况下（向右深入），算法的执行效率会受到微弱影响。
    • 如果数组中存在多个数值等于 e 的重复元素，一旦中间的 S[mi] 碰巧等于 e，算法就会立刻执行 return mi; 退出。这导致它无法保证返回的是这群重复元素中位置最靠右（秩最大）的那一个。

    5.1.4 时间复杂度分析

    因为每一次迭代，向左的代价是1，向右的代价是2，平均下来每深入一层（将区间折半一次）大约需要 (1+2)/2=1.5(1+2)/2 = 1.5(1+2)/2=1.5 次比较。

    • ASLsucc=O(1.50⋅log⁡n)ASL_{succ} = \mathcal{O}(1.50 \cdot \log n)ASLsucc​=O(1.50⋅logn)

    • ASLfail=O(1.50⋅log⁡n)ASL_{fail} = \mathcal{O}(1.50 \cdot \log n)ASLfail​=O(1.50⋅logn)

    5.2 版本B

    5.2.1 代码叙述

    template <typename T> int binSearch( T* S, const T& e, int lo, int hi ) {
    if ( e < S[lo] ) return lo - 1; //相当于e = -inf
    
    while ( 1 < hi - lo ) { //每步迭代一次比较、两个分支；不能提前终止
        
        int mi = (lo + hi) / 2; //以中位数为轴点，区间宽度折半
        
        if ( e < S[mi] ) hi = mi; //经比较后确定深入前缀[lo, mi)
        else lo = mi; //或后缀[mi, hi)
        
    } //出口时hi = lo + 1
    
    return lo;
} //binSearch

    5.2.2 逻辑叙述

    每次迭代仅做1次元素比较，只有2个分支方向（放弃命中的分支），即 [lo, mid)[\text{lo, mid})[lo, mid) 和 [mid, hi][\text{mid, hi}][mid, hi] 。因为减少了一次比较，所以整体计算时间有所降低。

    5.3 版本C

    5.3.1 代码叙述

    template <typename T> int binSearch( T* S, const T& e, int lo, int hi ) {
    
    while ( lo < hi ) { //不变性：[0, lo) <= e < [hi, n)
        
        int mi = (lo + hi) / 2;
        
        if ( e < S[mi] ) hi = mi; //[lo, mi)
        else lo = mi + 1; //(mi, hi)
        
    } //出口时，[lo = hi] = M
    
    return lo - 1; //至此，[lo]为大于e的最小者，故[lo-1] = m即为不大于e的最大者
} //binSearch

    5.3.2 逻辑叙述

    这个算法寻找的是数组中大于 eee 的第一个元素。

    在整个 while (lo < hi) 循环的推进过程中，算法始终维护着一个不变性：

    • [0, lo)：里面的元素全部 ≤e\le e≤e（不大于 eee）。

    • [hi, n)：里面的元素全部 >e> e>e（严格大于 eee）。

    • [lo, hi)：这是每一步需要用中位数 mi 去继续试探、不断缩小的区域。

    每次取中位数 mi = (lo + hi) / 2 后，只做一次比较：

    • 如果 e < S[mi]，说明当前的 S[mi] 和它右边的所有元素都大于 eee，那么右侧战线就可以安全地向左推进，令 hi = mi。

    • 如果 S[mi] <= e），说明当前的 S[mi] 和它左边的一切元素都 ≤e\le e≤e，那么左侧战线就可以安全地向右推进。由于 S[mi] 本身安全，左边界可以直接越过它，令 lo = mi + 1。

    哪怕此时 S[mi] 刚好等于 e，算法也不会停下来，而是直接划入 else 分支，强行令 lo = mi + 1，继续向右逼近。

    当 lo == hi 时，中间的盲区完全消失（此时 lo == hi == M）。既然 [hi, n) 严格 >e> e>e，那么此时的 S[lo]（即 S[M]）就是整个数组中大于 eee 的最小元素。既然 S[lo] 是第一个大于 eee 的元素，那么它的前一个位置 lo - 1，自然就是整个数组中不大于 eee 的最大元素。

    七、起泡排序

    7.1 基础起泡排序

    template <typename T>
void Vector<T>::bubbleSort( int lo, int hi ) {
    while ( lo < --hi ) //逐趟起泡扫描
        for ( int i = lo; i < hi; i++ ) //逐对检查相邻元素
            if ( _elem[i] > _elem[i + 1] ) //若逆序
                swap( _elem[i], _elem[i + 1] ); //则交换
}

    这个排序的时间复杂度永远是 O(n2)O(n^{2})O(n2)。

    7.2 提前终止的起泡排序

    引入一个 sorted 布尔标志位来进行优化（若某一趟扫描没有发生任何交换，说明已经有序，直接提前退出）。

    template <typename T> void Vector<T>::bubbleSort( int lo, int hi ) {
    for ( bool sorted = false; sorted = !sorted ; hi-- )
        for ( int i = lo + 1; i < hi; i++ )
            if ( _elem[i - 1] > _elem[i] )
                swap( _elem[i - 1], _elem[i] ), sorted = false;
}

    7.3 跳跃的起泡排序

    若最后被交换的是[last−1][\text{last}-1][last−1]和[last][\text{last}][last]，则[last, hi)[\text{last, hi})[last, hi)必然均已就位。可以跳过这个后缀，直接对[lo, last)[\text{lo, last})[lo, last)继续做起泡扫描。

    template <typename T> void Vector<T>::bubbleSort( int lo, int hi ) {
    for ( int last ; lo < hi; hi = last )
        for ( int i = (last = lo) + 1; i < hi; i++ )
            if ( _elem[i - 1] > _elem[i] )
                swap( _elem[i - 1], _elem[i] ), last = i;
}

    八、归并排序

    8.1 代码描述

    // 1. 主控制流程：递归分治
template <typename T> void Vector<T>::mergeSort( int lo, int hi ) {
    if ( hi - lo < 2 ) return; //单元素自然有序，否则
    int mi = ( lo + hi ) / 2; //均分为前缀、后缀
    mergeSort( lo, mi ); mergeSort( mi, hi ); //各自排序
    merge( lo, mi, hi ); //归并 (实质的计算) , O(n)
} //mergeSort, O(nlogn)

// 2. 核心计算：二路归并算法
template <typename T> void Vector<T>::merge( int lo, int mi, int hi ) {
    int s = 0; T* S = _elem + lo; //就地归并至序列S[0, hi-lo)
    
    int a = 0, la = mi - lo; T* A = new T[la]; //A[0, la)复制自
    for ( int i = 0; i < la; i++ ) A[i] = S[i]; //S的前缀
    
    int b = 0, lb = hi - mi; T* B = S + la; //B[0, lb)就是S的后缀
    
    // 反复地比较A、B的首元素
    while ( ( a < la ) && ( b < lb ) ) {
        // 小者优先归入S
        S[s++] = ( A[a] <= B[b] ) ? A[a++] : B[b++];
    }
    
    // 若B先耗尽，则
    while ( a < la ) {
        S[s++] = A[a++]; //将A残余的后缀归入S中——若A先耗尽呢？
    }
    
    delete[] A; //new和delete很耗时，如何减少?
}

    8.2 算法描述

    策略：

    1. 递归基：如果当前区间长度小于 2（hi - lo < 2），说明只剩 1 个元素。单个元素天然有序，直接返回。

    2. 切分盲区：取中位数 mi，把整个大问题一刀切成两个几乎等长的小区间：前缀 [lo, mi) 和后缀 [mi, hi)。

    3. 向下分治：对左边和右边分别递归调用 mergeSort，直到两边各自变得完全有序。

    merge 函数中，通过一个 while 循环，同时用指针 a 和 b 扫描 A 和 B：

    S[s++] = ( A[a] <= B[b] ) ? A[a++] : B[b++];

    由于 merge 会被频繁递归调用，频繁地 new 和 delete 临时数组 A 会带来巨大的系统开销。一般在外部包裹函数中，一次性申请一块与原数组总长度相等的巨大辅助空间，并将该空间的指针作为参数在递归调用时一路向下传递。

    九、位图

    位图的精髓在于：用一个连续的字节数组 M，去模拟一个拥有 n 位的布尔数组 B[0, n)。

    9.1 空间向上取整公式：N = (n + 7) / 8

    在 init 函数中，输入需要存储的总位数 n，算法需要计算出应该申请多少个字节（Byte）的空间 N。(n + 7) / 8 是一个经典的位运算技巧，等价于对 n / 8 进行向上取整。

    • 若 n=8→(8+7)/8=1n = 8 \rightarrow (8+7)/8 = 1n=8→(8+7)/8=1 字节
    • 若 n=9→(9+7)/8=2n = 9 \rightarrow (9+7)/8 = 2n=9→(9+7)/8=2 字节（完美容纳第 9 位）

    9.2 找到第 k 位

    要在字节数组 M 中操作绝对位置为 k 的二进制位，需要经过两步数学转换：

    • 第一步：算出在第几个字节（Byte 索引）

      i=k/8(或者用位移 k>>3)i = k / 8 \quad (\text{或者用位移 } k >> 3)i=k/8(或者用位移 k>>3)

    • 第二步：算出在当前字节内的第几位（Bit 索引）

      j=k%8(或者用位与 k&7)j = k \% 8 \quad (\text{或者用位与 } k \& 7)j=k%8(或者用位与 k&7)

    9.4 Initializing an Array in O(1)O(1)O(1) Time：拆分数组+校验环

    如果我们需要一个能够记录三种状态（比如：未访问、已标记、已删除）的物理大数组 B[N]，在刚开辟空间时，里面的内存全是系统残留的“垃圾随机值”。本方式通过额外的机制，一眼就能识别出某个位置的数值到底是“用户后来写的”，还是“原本就有的垃圾值”。

    为了区分状态，引入两个辅助数组和一个计数器：

    1. F[N] (From 数组)：大小与原数组相同，用来配合记录信息。

    2. T[N] (To 数组)：它是一个紧凑的栈，所有被真正用户赋值过的节点，都会在 T 中按顺序从左到右无缝排列。

    3. size 计数器：记录当前用户一共往数组里有效写入了多少个数据。此时，T[0, size) 区间内全是有效数据。

    核心判据：

    T[F[k]]==k&&F[k]<sizeT[F[k]] == k \quad \&\& \quad F[k] < \text{size}T[F[k]]==k&&F[k]<size

    9.4.1 O(1)O(1)O(1) 插入

    1. 防重复检查：先通过双向校验环判断 k 是否已经存在。如果已经存在，说明是覆盖写，直接改 B[k] 即可。

    2. 建立新链接：如果是一个全新的 k，则在紧凑栈顶 size 处与其建立“虎符契约”。

    void insert(Rank k, T value) {
    // 1. 如果之前没写入过，才需要建立双向链接
    if ( !isValid(k) ) { 
        F[k] = size;     // F[k] 指向当前栈顶
        T[size] = k;     // 栈顶 T[size] 反向指回 k
        size++;          // 栈顶指针上移
    }
    B[k] = value;        // 写入实际数据
}

    9.4.2 O(1)O(1)O(1) 删除

    • 定位：通过 From 数组直接获取 kkk 在紧凑栈 TTT 中的位置索引，令 r=F[k]r = F[k]r=F[k]。

    • 覆盖：获取当前栈顶（最后一位）的元素，令 last_k=T[size−1]last\_k = T[size - 1]last_k=T[size−1]。随后用 last_klast\_klast_k 直接覆盖 T[r]T[r]T[r]，填补因删除 kkk 产生的空洞。

    • 重定向：更新栈顶元素的逆向映射，令 F[last_k]=rF[last\_k] = rF[last_k]=r，使其重新与新位置配对。

    • 缩栈：执行 size=size−1size = size - 1size=size−1，将原栈顶空间释放，此时元素 kkk 彻底从有效逻辑区间中移除。

    void remove(Rank k) {
    if ( !isValid(k) ) return; // 本来就不存在，直接返回
    
    Rank r = F[k];             // 拿到 k 在 T 数组中的索引
    Rank last_k = T[size - 1]; // 拿到当前紧凑栈的最后一个元素
    
    // 用最后一个元素覆盖掉被删除的元素
    T[r] = last_k;             
    F[last_k] = r;             // 修正最后一个元素的指回方向
    
    size--;                    // 安全缩减栈规模，此时 k 已经被排除在外
}
